## 三条硬规则

### 1. 截面积分 → 必须过整体量

$$\int_A\tau\,\mathrm dA=F_S,\qquad \int_A\sigma\,\mathrm dA=N,\qquad \int_Ay\sigma\,\mathrm dA=M$$

```python
import numpy as np
y = np.linspace(-h/2, h/2, 200001)
print(np.trapz(tau(y)*b, y)/F_S)     # 必须 = 1.0000
```

**踩过的坑**：矩形截面静矩写成 $\frac b2(\frac h2-y)^2$（正确是 $\frac b2(\frac{h^2}4-y^2)$），
导致 $\int\tau\mathrm dA=2F_S$，剪应力合力差 5 倍。

### 2. 分段刚度 → 必须建有限元

EI 沿杆长变化时，禁止手算 $\iint$ 求位移：

```python
def kbeam(EI, Le):
    return EI/Le**3*np.array([[12,6*Le,-12,6*Le],[6*Le,4*Le*Le,-6*Le,2*Le*Le],
                              [-12,-6*Le,12,-6*Le],[6*Le,2*Le*Le,-6*Le,4*Le*Le]])
```

**踩过的坑**：悬臂梁固定端在 A、自由端在 D，问 C 点挠度。
我把积分区间取成 C→D（把 C 当成固定端），得 4.58 m；正确应积 A→C，得 48 mm。**差 95 倍。**

### 3. 二力杆 / 桁架 → 必须先跑 `truss_solve`

```json
mcp__mech-solver__truss_solve(nodes, members, supports, loads)
```

先看各杆内力**比**，再谈临界力与截面配比。

**踩过的坑**：令两杆临界力相等来配刚度，忘了载荷按几何分配（$N_{AH}/N_{AB}=\sqrt3$），
答案从 $\sqrt3$ 错成 3。`truss_solve` 一次调用就能看到内力比。

> 三个节点两根杆时，两个支座都要设 `pin`，否则报"几何可变 $m+r-2N=-1$"。

## 工具救不了的部分：建模漏项

模型本身缺因子、符号反了，工具会忠实按错模型算。只能用：

| 手段 | 做法 |
|---|---|
| 能量法 | 动能/势能另推一遍，与牛顿-欧拉比对 |
| 极限情形 | $y\to0$、$\alpha\to0$、$k\to0$、$\theta\to0$ 是否退化为已知解 |
| 量纲 | 系数无量纲、数量级合理 |
| 对称性 | 对称结构对对称载荷，内力/位移应对称 |

## 三个警报

1. **结果与直觉差一个量级以上** → 先怀疑自己，别怀疑题目。第十四届第 5 题 4.58 m 就是警报，我按了静音。
2. **出现 1/32、1/1024 这类过分整齐的系数** → 立刻对照整体量，多半漏了因子。
3. **只有单一方法得到的结果** → 必须补第二条路径。
