| 量 | 约定 |
|---|---|

## 三、题型 → 该用什么（决策表）

| 题目特征 | 首选方法 | 备用 / 校验 |
|---|---|---|
| 求支座反力，静定 | 平衡方程 ΣF=0, ΣM=0 | 虚位移原理 |

## 四、三类高频题的解题骨架

### A. 点的合成运动（周培源常考）

```
1. 选动点（一般选接触点/滑块）、动系（固连在运动刚体上）、静系（地面）
2. 写速度合成：v_a = v_e + v_r        （三者构成闭合三角形）
3. 加速度合成：a_a = a_e + a_r + a_C
   动系平动 → a_C = 0
   动系转动 → a_C = 2ω_e × v_r（方向：v_r 沿 ω_e 转 90°）
4. 画矢量图，投影到两个方向解出未知量
5. 校核：量纲 + 极端位置（如 ω→0 应退化为静止）
```

**易错**：把牵连速度写成动系原点的速度；忘记 a_C；法向加速度 a_n = v²/ρ 的 ρ 取错。

### B. 刚体平面运动

```
1. 判运动类型：平动 / 定轴转动 / 平面运动
2. 速度：瞬心法（找两条速度垂线交点）或 v_B = v_A + ω×r_BA
3. 加速度：基点法 a_B = a_A + α×r_BA + ω×(ω×r_BA)
   最后一项即法向分量 ω²·r，方向指向基点
4. 关联约束（绳、齿、纯滚）给出 v、a 的补充方程
5. 校核：纯滚时 v_C=0（接触点）、a_C 只有法向分量
```

### C. 动力学三大定理的选择

```
已知量 → 求什么 → 选定理
  力求加速度 / 加速度求力   → 牛顿-欧拉（或达朗贝尔）
  力求速度 / 位移            → 动能定理
  时间 + 力求速度            → 动量定理 / 动量矩定理
  多自由度 / 复杂约束        → 拉格朗日方程
```

**校验套路**：算完用另一条定理验一遍（如用动能定理的结果代回牛顿方程看是否自洽）。

## 五、量纲检查清单（评分「表达」项）

| 量 | 量纲（SI） |
|---|---|
| 力 | N = kg·m/s² |
| 力矩 | N·m |
| 应力 | Pa = N/m² |
| 应变 | 无量纲 |
| 挠度 | m |
| 抗弯刚度 EI | N·m² |
| 固有频率 | rad/s 或 Hz（差 2π，注意） |
| 动量 | kg·m/s |
| 动能 | J = N·m |

**快速判据**：结果里若出现「长度²/力」，多半是柔度；「力·长度」是力矩/能量。

## 六、答案书写模板（对应评分权重）

```
【解】
约定：x 向右、y 向上；弯矩下侧受拉为正。

1. 受力分析（列全部外力与反力，画简图）
2. 列方程 / 选定理  ← 写清「为什么用这条定理」
3. 求解（关键中间结果保留符号）
4. 结果：M_max = ... N·m（方向：...）
5. 校核：① 量纲 ② 回代 ③ 极限情形 → 三项均通过
```

过程分（20%）主要看第 2、5 步；表达分（10%）看约定、单位、校核是否齐全。
