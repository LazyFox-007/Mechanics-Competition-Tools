# 建模决策卡（自研）

> 与 `mcp/mech-model` 配套。本文件是**人读 + 省 token 版**，工具是**强制检查版**。
> 不含任何赛题答案，只有判据与后果链。

## 什么时候用

**动笔之前**。不是算完检查，是建模之前。

实测结论（第十四届，120 分）：失分最重的不是算错，是**建模轴沉默默认**。
第 6 题 −17 分，全部来自两条没被问出口的问题：

- 锥面滚动半径沿横向朝哪边增大？
- 轮对轴线能不能绕纵向轴倾斜？

两个都走了默认，两个默认都是错的。

## 铁律

> **每条建模决策必须有 evidence；`assumed` 不算 evidence。**

| evidence | 含义 |
|---|---|
| `statement` | 题干明说 |
| `figure` | 图上读出来的（需裁图放大确认） |
| `textbook` | 教材/常识，写明依据 |
| `derived` | 由其他已声明条件推得，写明推法 |

写在答案开头的「约定」一行，就是这套声明的入口。

## 三条通用轴（每题都查）

| 轴 | 常见默认 | 后果 |
|---|---|---|
| 符号约定 | 不写，凭感觉 | 答案符号全错且无法自检；过程分扣光 |
| 小变形 / 大变形 | 一律当小变形 | $(θ-\tanθ)/θ>5\%$ 时挠度荒谬（实测：48 mm 与 9.3 m 之差） |
| 死载 / 随动 | 不区分 | 力臂取错：死载取到作用线的垂直距离，随动取弧长 |

## 六类题型的高风险轴

只列**最容易被默认搞错**的那一两条；完整轴用 `model_card(action="list")` 取。

### 静力 / 摩擦 / 翻转
- **临界状态枚举了几种**：滑动 2 种 + 翻转 2 种，共 4 种。只算滑动 → 区间上界被高估（上界常由翻转控制）。
- **中间铰是内铰还是支座**：内铰不提供反力且 $M=0$；写成支座铰 → 静定变静不定。

### 多自由度系统（齿轮系 / 曲柄连杆）
- **转动惯量对哪个点取**：定轴转动取轴心（$mL^2/3$），平面运动取质心 + 平行轴定理。
- **附加质量（焊块/偏心）是否同时进了 $T$ 与 $V$**：只进一处会同时丢惯量项和重力项。
- **势能符号**：$V=-mg\,h$ 与 $V=+mg\,h$ 反号会让平衡位置变到补角、稳定性结论反过来。

### 梁 / 截面 / 强度理论
- **阴影区/条带的 $y$ 区间**：必须从图换算到形心坐标，并核 $\int_A \mathrm dA$ = 该区面积。
- **是否承认中性轴纯剪也是危险点**：$l/h$ 小时剪切控制，只算上下边缘会漏掉真正危险点。

### 曲杆 / 冲击 / 稳定
- **测点是纯弯还是弯+扭**：$T\neq0$ 就必须按平面应力算。
- **45° 应变片是否含泊松与剪应变**：$\varepsilon_\theta=\varepsilon_x\cos^2\theta+\varepsilon_y\sin^2\theta+\gamma\sin\theta\cos\theta$，三项都要查。
- **单边接触（间隙）是否已判定闭合**：先算无支承位移，与间隙比，再决定否引入支承。
- **压杆 $\mu$**：铰-铰 1.0 / 固-自由 2.0 / 固-固 0.5 / 固-铰 0.7；**框架柱顶无剪力按悬臂柱 $\mu=2$**。

### 分段变截面大变形（elastica）
- **力臂取哪个量**：死载取「到作用线的垂直距离」，且该距离随变形变、与位移耦合；用未变形距离 = 线性化解，与「大转角」前提矛盾。
- **载荷是死载还是随动**：细线拉、重力拉是死载；随动载荷力臂取弧长。
- **$\theta$ 分段**：$\varphi$ 与 $M$ 在 EI 突变处连续，但 $\varphi'=M/EI$ 跳变——不能共用一个 $EI$ 除到底。

### 轮轨 / 锥形轮对
- **锥度方向**（最高风险）：半径**向辋内（法兰侧）增大**。取反会让 $r(y)$ 反号，连锁影响接触点纵向速度 → 蠕滑力 → 横摆方程耦合项，一错全错。判别：轮对侧移后轮缘是靠近还是远离钢轨。
- **轴线能否倾斜**：两轮滚动半径不等而两轨同高 ⇒ 轴线**必然**倾斜，倾角与横向位移由轮距和锥度联系。漏掉该自由度，侧向力系数会少一个因子。

## 与其他工具的分工

```
题干 → model_card(action=probe)      选题型
     → model_card(action=list)       摆出活决策轴
     → 逐轴填 value + evidence
     → model_card(action=check)      block → 不许往下算
     → 求解器（truss_solve / lagrange_eom / buckling_solve …）
     → 验算（F/B/L + scan_extremum / numeric_compare）
```

**这个工具不替你建模，只不让你偷偷假设。**
