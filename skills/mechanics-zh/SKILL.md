# 中文力学速查（自研）

> 本 skill 为**自研整理**，不含任何受版权保护的教材原文，可自由使用与修改。
> 系统教材（英文，含公式与例题）见 `mechanics-map` skill。

---

## 什么时候用

| 情形 | 本 skill 提供 |
|---|---|
| 题目是中文，术语拿不准对应哪个英文概念 | 术语对照表 |
| 动笔前要统一符号与正负号 | 约定表（N/Q/M/T、应力、转角） |
| 不知道该用哪条定理 | 题型 → 方法决策表 |
| 卡在「这类题从哪下手」 | 三类高频题骨架（合成运动 / 平面运动 / 三大定理） |
| 结果不确定对不对 | 量纲检查清单 |
| 不知道怎么排版答案才拿过程分 | 答案书写模板 |

---

## 内容

**`modules/01-速查.md`** 六节：

1. **术语对照** —— 静力学 / 运动学 / 动力学，中英并列
2. **符号与正负号约定** —— 轴力拉为正、剪力顺时针为正、弯矩下侧受拉为正…每题的答案开头都要声明
3. **题型 → 方法决策表** —— 12 类题目特征对应首选方法与校验手段
4. **三类高频题骨架** —— 点的合成运动、刚体平面运动、动力学定理选择
5. **量纲检查清单** —— 常见量纲 + 快速判据
6. **答案书写模板** —— 对应「答案 70% + 过程 20% + 表达/校核 10%」

## 和别的工具怎么配合

```
中文题 → mechanics-zh（定约定、选方法）
       → mechanics-map（查该方法的英文标准流程与例题）
       → mcp__sympy__*（符号推导、解方程）
       → 插件 mech_analyze / mech_diagram（静定内力图）
       → mechanics-zh 的量纲清单 + 书写模板（收尾校核与排版）
```
