# 材料力学模块 (Material Mechanics)

## 适用范围

**材料力学**：拉压与连接件、扭转、弯曲内力与应力、弯曲变形、应力状态与强度理论、组合变形、能量法、静不定、压杆稳定、动载荷、疲劳。

本模块的定位是**补 `mechanics.md` 没有覆盖的一半考纲**——周培源个人赛是理论力学与材料力学合卷，缺了这半边等于半盲。

（子域标准结构：识别特征 → 建模步骤 → 验证组合 → 适用条件 → 常见错误表；验证代号 F/D/B/C/L/E/I/J 定义见 `verification_engine.md`）

**符号约定（与 `dsh-mech-workbench` 的 `mech_analyze` / `mech_diagram` 完全一致，不得自行改动）**：

- 轴力 **N：拉为正**
- 剪力 **Q：使微段顺时针转为正**
- 弯矩 **M：下侧受拉为正**
- 扭矩 **T：右手螺旋沿 +x 为正**
- 横向集中力向上为正；分布集度 q 向上为正；集中力偶逆时针为正
- 默认单位 `m / kN / kN·m / MPa`

## 0. 方法选择表

按问题结构选解法；能选**可独立复核**的解法优先。

| 系统特征 | 首选方法 | 选择理由 | 本域特化验证 |
|---|---|---|---|
| 静定杆系，求反力/内力 | 截面法 + 平衡（§1、§3） | 直接，残差可查 | B 平衡方程回代 |
| 静定梁，求变形 | 积分法 / 叠加法 / 共轭梁（§5） | 挠曲线方程可直接回代边界条件 | B 边界条件 + L（EI→∞ 时挠度→0） |
| 超静定（多余约束） | 力法 + 变形协调（§9） | 把超静定化为静定基本体系 | I 力法 vs 位移法；B 协调方程 |
| 求某点位移（任意结构） | 单位载荷法 / 莫尔积分（§8） | 单点位移一重积分，不必解整体 | I 与叠加法/积分法互校 |
| 刚度分段常量、M 图为直线/折线 | 图乘法（§8） | 手算最快 | E 抽样（数值积分对照） |
| 复杂应力状态 | 主应力 + 强度理论（§6） | 先化为一维主应力再套理论 | J 特征值回代 + I 莫尔圆互校 |
| 组合变形（拉弯扭） | 危险点应力叠加（§7） | 分解为基本变形分别算再叠加 | I 危险点交叉校核 |
| 细长受压杆 | 欧拉公式（§10） | 与柔度判据绑定 | D 柔度范围必查 |
| 冲击/惯性载荷 | 动荷系数法（§11） | 静载结果乘系数 | L（h→0 时 Kd→2） |

## 1. 拉压与连接件

### 识别特征

- 等直杆轴向外力；桁架杆件；螺栓/铆钉/焊缝连接。
- 待求：轴力、正应力、变形、连接件剪切与挤压强度。

### 建模步骤

1. 截面法求轴力 $N(x)$，画轴力图（拉正压负）。
2. 正应力 $\sigma = N/A$；变截面或自重问题分段积分。
3. 变形 $\Delta l = \dfrac{Nl}{EA}$；多段叠加 $\Delta l=\sum \dfrac{N_i l_i}{E_i A_i}$。
4. 横向应变 $\varepsilon' = -\nu\varepsilon$，$\Delta d = -\nu \varepsilon d$。
5. 连接件：剪切 $\tau = \dfrac{F}{nA_s}\le[\tau]$，挤压 $\sigma_{bs}=\dfrac{F}{d\,t}\le[\sigma_{bs}]$。
6. 强度条件 $\sigma_{max}\le[\sigma]$；变截面杆危险截面在 $N/A$ 最大处，**不在 N 最大处**。

### 验证组合

推荐 F + B + E；桁架题加 I（节点法 vs 截面法）。

### 必须检查的适用条件

- 圣维南原理：集中力附近应力分布不适用 $\sigma=N/A$，需距端部足够远。
- 材料线弹性、小变形；塑性阶段不适用。
- 连接件的实用计算是**工程近似**，不是精确解，须声明。

### 常见错误

| 错误 | 正确 |
|---|---|
| 认为 N 最大处最危险 | 比较 $N/A$，变截面处常更危险 |
| 挤压面积取圆柱面 | 取**投影面积** $d\cdot t$ |
| 忘记自重 | 长杆/高柱须计入 $\rho g A$ 分布轴力 |
| 拉压刚度用 $EI$ | 用 $EA$ |

## 2. 扭转

### 识别特征

- 圆轴受扭矩；传动轴功率—转速换算。
- 待求：扭矩图、切应力、扭转角、刚度校核。

### 建模步骤

1. 外力偶 $M_e = 9549\dfrac{P(\mathrm{kW})}{n(\mathrm{r/min})}$（N·m）。
2. 截面法画扭矩图 T(x)。
3. 切应力 $\tau_\rho=\dfrac{T\rho}{I_p}$，$\tau_{max}=\dfrac{T}{W_p}$。
   - 实心圆：$I_p=\dfrac{\pi d^4}{32}$，$W_p=\dfrac{\pi d^3}{16}$
   - 空心圆：$I_p=\dfrac{\pi(D^4-d^4)}{32}$，$W_p=\dfrac{\pi D^3}{16}\left(1-\alpha^4\right)$，$\alpha=d/D$
4. 扭转角 $\varphi=\dfrac{Tl}{GI_p}$；刚度条件 $\theta=\dfrac{T}{GI_p}\le[\theta]$（rad/m）。
5. 强度条件 $\tau_{max}\le[\tau]$。

### 验证组合

推荐 F + B + L；刚度题加 E。

### 必须检查的适用条件

- **圆截面**才可用 $\tau=T\rho/I_p$；非圆截面（矩形、椭圆）须查表，$\tau_{max}$ 在长边中点。
- 闭口薄壁 vs 开口薄壁的扭转刚度差数量级，不可混用公式。
- 塑性材料扭转破坏为剪断（45° 螺旋面），脆性为拉断——判据不同。

### 常见错误

| 错误 | 正确 |
|---|---|
| 非圆截面套 $W_p=\pi d^3/16$ | 矩形 $W_t=\alpha b^2 h$，查表 |
| 空心轴忘 $1-\alpha^4$ | $W_p$、$I_p$ 都要乘该因子 |
| 扭转角用 $EI$ | 用 $GI_p$ |
| 功率换算漏 9549 | $M_e=9549P/n$，不是 $P/n$ |

## 3. 弯曲内力

### 识别特征

- 梁受横向载荷；需剪力图 Q 与弯矩图 M。
- 待求：支座反力、内力方程、极值与危险截面。

### 建模步骤

1. 求反力（静定：3 个平衡方程）。
2. 分段：**集中力、集中力偶、分布载荷的端点**都是分段点。
3. 用左段平衡写内力：
   $$N=-\sum_{a<x}F_x,\quad Q=+\sum_{a<x}F_y,\quad M=+\sum_{a<x}\left[(x-a)F_y-M_z\right]$$
   自动满足 $\dfrac{dM}{dx}=Q$，$\dfrac{dQ}{dx}=q(x)$。
4. 画图；标出极值、零线、跳变。
5. 校核：$\sum F=0$、$\sum M=0$、简支端 $M=0$、$dM/dx=Q$。

### 验证组合

推荐 F + B + E；复杂载荷加 I（左段 vs 右段独立求同一截面内力）。

### 必须检查的适用条件

- 内力符号约定必须全程一致；换约定等于换答案。
- 中间铰处 $M=0$，须按铰拆成两段建模。
- 分布载荷覆盖非整段时，积分区间取 $[x_0,\min(x_1,x)]$。

### 常见错误

| 错误 | 正确 |
|---|---|
| 集中力偶处 M 图不断开 | 力偶处 M 有**跳变**，Q 连续 |
| 简支梁端部 M≠0 | 铰/辊轴端 M 必为 0 |
| 弯矩图凹凸方向搞反 | 均布载荷段 M 为二次抛物线 |
| 分段点漏掉力偶作用点 | 力偶位置必须分段 |

## 4. 弯曲应力

### 识别特征

- 梁的横截面正应力、切应力；需校核强度。
- 待求：$\sigma_{max}$、$\tau_{max}$、危险点位置。

### 建模步骤

1. 截面几何：$I_z$（对中性轴）、$W_z=I_z/y_{max}$；组合截面先求形心再**移轴** $I=I_c+Ad^2$。
2. 正应力 $\sigma=\dfrac{My}{I_z}$，$\sigma_{max}=\dfrac{M_{max}}{W_z}$。
3. 切应力 $\tau=\dfrac{QS_z^*}{I_z b}$：
   - 矩形：$\tau_{max}=\dfrac{3Q}{2A}$
   - 圆形：$\tau_{max}=\dfrac{4Q}{3A}$
   - 工字形：$\tau_{max}\approx\dfrac{Q}{h\,d}$（腹板）
4. 强度条件 $\sigma_{max}\le[\sigma]$，$\tau_{max}\le[\tau]$。
5. 脆性材料需**分别校核**拉压两侧（$[\sigma_t]\neq[\sigma_c]$）。

### 验证组合

推荐 F + B + J；组合截面必做 J（形心与移轴回代）。

### 必须检查的适用条件

- 平面弯曲假设：载荷作用在形心主惯性平面内；斜弯曲须分解。
- $\sigma=My/I_z$ 仅适用线弹性、小变形；$\tau=QS/(Ib)$ 仅适用**实体截面**（薄壁需剪力流法）。
- 中性轴过形心——组合截面若算错形心，一切作废。

### 常见错误

| 错误 | 正确 |
|---|---|
| 组合截面直接加 $I$ | 先求形心，再移轴 $I=I_c+Ad^2$ |
| 切应力公式的 b 取错 | b 取**中性轴处**的截面宽度 |
| 脆性材料只校核受拉侧 | 拉压许用不同，两侧都查 |
| 单位 mm 直接代 | 统一到 m 或统一到 mm·N |

## 5. 弯曲变形

### 识别特征

- 求挠度 v、转角 θ；刚度校核；超静定梁的变形协调。
- 待求：特定点位移或最大挠度。

### 建模步骤

1. 写弯矩方程 $M(x)$，用 $EI\,v''=M(x)$（注意符号与 M 正负约定一致）。
2. 积分两次得 $EI\,v'$、$EI\,v$，用**边界条件**定两个常数：
   - 固定端：$v=0$、$v'=0$
   - 铰/辊轴：$v=0$
   - 中间铰：两侧 $v$ 相等且 $M=0$
3. 分段时每段两个常数，用**连续条件**（$v$、$v'$ 在分段点连续）衔接。
4. 叠加法：查标准梁表叠加，注意**同一点同一方向**才能直接相加。
5. 共轭梁法：把 M 图当虚载荷，边界条件按支座类型对偶转换。
6. 刚度条件 $v_{max}\le[v]$，$[\theta]$ 按规范。

### 验证组合

推荐 B + L + E；超静定梁必加 I（力法 vs 积分法）。

### 必须检查的适用条件

- 小变形、线弹性；大挠度需用非线性理论。
- 叠加法要求各载荷**同一梁、同一坐标系**，且变形可线性叠加。
- $EI\,v''=M$ 的符号取决于 M 与 v 的正向约定，混用会导致挠度方向反。

### 常见错误

| 错误 | 正确 |
|---|---|
| 积分常数不按边界条件定 | 每段 2 个常数，靠边界+连续条件定 |
| 叠加时把不同点位移相加 | 只加同一点同一方向 |
| 忽略分段点连续性 | $v$、$v'$ 必须连续 |
| 符号约定与 M 图不一致 | 先统一 M 与 v 的正向再写方程 |

## 6. 应力状态与强度理论

### 识别特征

- 已知 $\sigma_x,\sigma_y,\tau_{xy}$ 求主应力、最大切应力；或判断危险点。
- 待求：$\sigma_1,\sigma_2,\sigma_3$、$\tau_{max}$、相当应力 $\sigma_r$。

### 建模步骤

1. 取单元体，标出各面应力（含正负号）。
2. 主应力：
   $$\sigma_{1,2}=\frac{\sigma_x+\sigma_y}{2}\pm\sqrt{\left(\frac{\sigma_x-\sigma_y}{2}\right)^2+\tau_{xy}^2}$$
   平面应力下 $\sigma_3=0$，**注意排序** $\sigma_1\ge\sigma_2\ge\sigma_3$。
3. 主方向 $\tan 2\alpha_0=-\dfrac{2\tau_{xy}}{\sigma_x-\sigma_y}$。
4. $\tau_{max}=\dfrac{\sigma_1-\sigma_3}{2}$。
5. 强度理论（$\sigma_r$ 与 $[\sigma]$ 比较）：

| 理论 | 相当应力 $\sigma_r$ | 适用 |
|---|---|---|
| 第一（最大拉应力） | $\sigma_1$ | 脆性材料受拉 |
| 第二（最大伸长线应变） | $\sigma_1-\nu(\sigma_2+\sigma_3)$ | 脆性材料，少用 |
| 第三（最大切应力） | $\sigma_1-\sigma_3$ | 塑性材料 |
| 第四（畸变能） | $\sqrt{\tfrac12\left[(\sigma_1-\sigma_2)^2+(\sigma_2-\sigma_3)^2+(\sigma_3-\sigma_1)^2\right]}$ | 塑性材料，更精确 |

### 验证组合

推荐 F + J + I；J 必做（特征值回代、$\mathrm{tr}=\sum\sigma_i$、$\det=\prod\sigma_i$）。

### 必须检查的适用条件

- 强度理论有适用范围：脆性用第一/第二，塑性用第三/第四；选错的理论**算得再对也是错的**。
- 三向等拉时第三理论失效（$\sigma_1-\sigma_3=0$ 但材料会断），须用第一理论。
- $\sigma_3=0$ 的排序不能漏，否则 $\tau_{max}$ 与 $\sigma_r$ 全错。

### 常见错误

| 错误 | 正确 |
|---|---|
| 主应力不排序 | $\sigma_1\ge\sigma_2\ge\sigma_3$，符号也算 |
| 平面应力当 $\sigma_3=\sigma_z$ 忘记 | 平面应力 $\sigma_z=0$ 是**主应力之一** |
| 塑性材料用第一理论 | 用第三/第四 |
| 莫尔圆横纵比例不一致 | σ 轴与 τ 轴等比例，否则圆变椭圆 |

## 7. 组合变形

### 识别特征

- 同时存在两种以上基本变形：拉弯、弯扭、斜弯曲、拉弯扭。
- 待求：危险点位置与相当应力。

### 建模步骤

1. **分解**为基本变形，各自求内力/应力分布。
2. 找**危险截面**（内力最大）与**危险点**（应力叠加最大）。
3. 危险点应力叠加：
   - 拉（压）弯：$\sigma=\dfrac{N}{A}\pm\dfrac{M_y}{W_y}\pm\dfrac{M_z}{W_z}$（同号相加）
   - 弯扭组合（圆轴）：$\sigma=\dfrac{M}{W}$，$\tau=\dfrac{T}{W_p}$
     $$\sigma_{r3}=\frac{\sqrt{M^2+T^2}}{W},\qquad \sigma_{r4}=\frac{\sqrt{M^2+0.75\,T^2}}{W}$$
4. 按材料选强度理论校核。

### 验证组合

推荐 F + I + J；I 必做（分别用两个强度理论交叉，差异应在合理范围）。

### 必须检查的适用条件

- 叠加原理要求小变形、线弹性、各载荷效应独立。
- 圆轴弯扭公式中的 W 是**抗弯**截面模量，$W_p$ 是抗扭，别混。
- 危险点可能不在最大弯矩截面（有轴力时）。

### 常见错误

| 错误 | 正确 |
|---|---|
| 弯扭组合用 $\sigma+\tau$ 直接相加 | 用相当应力 $\sqrt{\sigma^2+4\tau^2}$ 或 $\sqrt{\sigma^2+3\tau^2}$ |
| 危险点只看 M 最大截面 | 综合 N、M、T，逐截面算 |
| 圆轴公式套到非圆轴 | 非圆截面须另行处理 |
| 拉弯叠加时符号搞错 | 同侧应力同号相加 |

## 8. 能量法

### 识别特征

- 求任意点位移、超静定、冲击；结构复杂不适合积分法。
- 待求：位移 $\Delta$、应变能 $U$。

### 建模步骤

1. 应变能（各基本变形）：
   $$U=\int\frac{N^2}{2EA}dx+\int\frac{M^2}{2EI}dx+\int\frac{T^2}{2GI_p}dx+\int\frac{kQ^2}{2GA}dx$$
   剪切项常忽略（细长梁），但**深梁/短粗杆**须计入。
2. 卡氏第二定理：$\Delta_i=\dfrac{\partial U}{\partial F_i}$（$F_i$ 为广义力，求位移处无载荷则加**虚设力**后令其为 0）。
3. 单位载荷法（莫尔积分）：$\Delta=\displaystyle\int\frac{M\bar M}{EI}dx+\int\frac{N\bar N}{EA}dx+\int\frac{T\bar T}{GI_p}dx$。
4. 图乘法：$\Delta=\sum\dfrac{\omega\,\bar M_C}{EI}$（$\omega$ 为 M 图面积，$\bar M_C$ 为单位载荷图在形心处的值）。
5. 功的互等 / 位移互等定理可用于校核。

### 验证组合

推荐 F + I + E；I 必做（图乘法 vs 积分法；卡氏 vs 单位载荷）。

### 必须检查的适用条件

- 线弹性、小变形；能量法**不适用**塑性或大变形。
- 图乘法要求：$EI$ 分段常量、至少一个图是**直线**、同侧异侧要带符号。
- 卡氏定理对**广义力**求偏导，力偶对应转角、力对应线位移。

### 常见错误

| 错误 | 正确 |
|---|---|
| 图乘法用于两个都是曲线 | 至少一个必须直线（或可分解为直线） |
| 图乘法忘符号 | 两图同侧为正、异侧为负 |
| 求位移处无载荷却直接对 0 求导 | 先加虚设力 $F_0$，求导后令 $F_0=0$ |
| 忽略剪切应变能 | 深梁、短粗杆须计入 $kQ^2/(2GA)$ |

## 9. 静不定

### 识别特征

- 未知反力数 > 平衡方程数；有多余约束。
- 待求：反力、内力、温度/装配应力。

### 建模步骤

1. 判定超静定次数：$n=\text{未知反力数}-\text{平衡方程数}$。
2. **力法**：去掉多余约束得静定基本体系，以多余未知力 $X_i$ 代替。
3. 写变形协调方程（典型方程）：
   $$\delta_{11}X_1+\delta_{12}X_2+\cdots+\Delta_{1P}=0$$
   柔度系数 $\delta_{ij}$ 用单位载荷法/图乘法求。
4. 解方程组得 $X_i$，回代求其余内力。
5. **温度应力**（超静定才有）：$\sigma=-E\alpha\Delta T$（全约束杆）。
6. **装配应力**：由制造误差引起的强制装配，同样靠协调方程求。

### 验证组合

推荐 B + I + L；B 必做（协调方程回代 + 平衡校核）。

### 必须检查的适用条件

- 力法要求基本体系**几何不变**且静定；选错基本体系方程会病态。
- 温度应力只在超静定结构中出现；静定结构温度变化**不产生应力**（自由膨胀）。
- 线弹性假定；塑性内力重分布超出本模块范围。

### 常见错误

| 错误 | 正确 |
|---|---|
| 静定结构算温度应力 | 静定结构温度变化无应力 |
| 协调方程符号写反 | 位移方向与假设的 $X_i$ 一致为正 |
| 忘记超静定次数判定 | 先数 $n$，再选 $n$ 个多余约束 |
| 只做平衡校核就交卷 | 必须验协调方程残差 |

## 10. 压杆稳定

### 识别特征

- 细长受压杆；问临界力、临界应力、是否失稳。
- 待求：$P_{cr}$、$\sigma_{cr}$、稳定校核。

### 建模步骤

1. 柔度 $\lambda=\dfrac{\mu l}{i}$，惯性半径 $i=\sqrt{\dfrac{I}{A}}$。
   长度系数 $\mu$：两端铰支 1.0；一端固定一端自由 2.0；两端固定 0.5；一端固定一端铰支 0.7。
2. 分档判据（材料常数 $\lambda_p$、$\lambda_s$ 查表）：
   - **大柔度** $\lambda\ge\lambda_p$：欧拉公式 $\sigma_{cr}=\dfrac{\pi^2E}{\lambda^2}$，$P_{cr}=\dfrac{\pi^2EI}{(\mu l)^2}$
   - **中柔度** $\lambda_s\le\lambda<\lambda_p$：经验直线 $\sigma_{cr}=a-b\lambda$
   - **小柔度** $\lambda<\lambda_s$：按屈服/强度处理，不失稳
3. 稳定校核两种写法：
   - 安全系数法 $n_{st}=\dfrac{P_{cr}}{P}\ge[n_{st}]$
   - 折减系数法 $\sigma=\dfrac{P}{\varphi A}\le[\sigma]$（$\varphi$ 查表）
4. 组合截面优先让材料远离形心（提高 $i$）；注意**失稳方向**取 $I_{min}$ 对应平面。

### 验证组合

推荐 D + B + L；D 必做（柔度落在哪一档，决定用哪个公式）。

### 必须检查的适用条件

- **欧拉公式只适用大柔度杆**（$\sigma_{cr}\le\sigma_p$）；中柔度用经验公式，小柔度不适用失稳判据。
- 欧拉公式要求材料服从胡克定律——失稳时应力必须仍在比例极限内。
- 两端约束条件决定 $\mu$，这是这类题最大的分歧来源。
- 稳定与强度**是两回事**：短粗杆可能强度先坏，细长杆稳定先坏。

### 常见错误

| 错误 | 正确 |
|---|---|
| 任何杆都用欧拉公式 | 先算 $\lambda$，判档 |
| $\mu$ 取 1 不管支承 | 四种典型支承对应 1.0/2.0/0.5/0.7 |
| 用 $I_{max}$ 算 $P_{cr}$ | 用 $I_{min}$（最易失稳方向） |
| 稳定校核只算强度 | 稳定与强度分别校核 |

## 11. 动载荷

### 识别特征

- 惯性力（加速/旋转构件）、冲击（落体、锤击）、振动。
- 待求：动应力、动荷系数。

### 建模步骤

1. **惯性载荷**：用达朗贝尔原理加惯性力，按静力问题处理。
   - 等加速提升：$K_d=1+\dfrac{a}{g}$
   - 匀速旋转圆环：$\sigma=\rho v^2$
2. **冲击**（能量法）：动荷系数
   $$K_d=1+\sqrt{1+\frac{2h}{\Delta_{st}}}\quad(\text{自由落体})$$
   - 突加载荷（$h=0$）：$K_d=2$
   - 水平冲击：$K_d=\sqrt{\dfrac{v^2}{g\Delta_{st}}}$
3. 动应力 $\sigma_d=K_d\,\sigma_{st}$，动变形 $\Delta_d=K_d\,\Delta_{st}$。
4. 提高抗冲击能力：增大 $\Delta_{st}$（加柔性、弹簧），降低 $K_d$。

### 验证组合

推荐 F + L + E；L 必做（$h\to0$ 时 $K_d\to2$，$h\to\infty$ 时 $K_d\to\infty$ 但 $\sigma_d$ 有限）。

### 必须检查的适用条件

- 冲击问题假设：**能量全部转化为应变能**、忽略质量与波的传播、材料仍线弹性。
- $K_d$ 是**近似**，冲击点局部塑性、接触变形未计入。
- 动载荷下的许用应力与静载不同（疲劳、脆性转变）。

### 常见错误

| 错误 | 正确 |
|---|---|
| 突加载荷当静载 | $K_d=2$，应力翻倍 |
| 冲击时用 $\sigma_d=K_d\sigma_{st}$ 但 $\Delta_{st}$ 算错 | $\Delta_{st}$ 是**同一位置同一方向**的静位移 |
| 认为加大截面总能提高抗冲击 | 加大刚度会降低 $\Delta_{st}$，反而提高 $K_d$ |
| 忽略惯性力 | 加速构件必须计入 |

## 12. 疲劳（简介）

- 循环特征 $r=\dfrac{\sigma_{min}}{\sigma_{max}}$；对称循环 $r=-1$，脉动 $r=0$。
- 疲劳极限 $\sigma_{-1}$ 由 S-N 曲线给出；持久极限对应 $10^7$ 次。
- 影响因素：应力集中（$K_\sigma$）、尺寸效应（$\varepsilon$）、表面质量（$\beta$）。
- 许用应力 $\left[\sigma_{-1}\right]=\dfrac{\sigma_{-1}}{n}\cdot\dfrac{\varepsilon\beta}{K_\sigma}$。
- **本模块只给判据，不给 S-N 曲线数据**——需要时查材料手册，不得编造。

## 13. 公式速查与跨域陷阱

### 核心公式

| 量 | 公式 |
|---|---|
| 拉压 | $\sigma=N/A$，$\Delta l=Nl/(EA)$ |
| 扭转 | $\tau_{max}=T/W_p$，$\varphi=Tl/(GI_p)$ |
| 弯曲正应力 | $\sigma=My/I_z$，$\sigma_{max}=M/W_z$ |
| 弯曲切应力 | $\tau=QS_z^*/(I_z b)$ |
| 挠曲线 | $EI\,v''=M(x)$ |
| 主应力 | $\sigma_{1,2}=\frac{\sigma_x+\sigma_y}{2}\pm\sqrt{\left(\frac{\sigma_x-\sigma_y}{2}\right)^2+\tau_{xy}^2}$ |
| 弯扭组合 | $\sigma_{r3}=\sqrt{M^2+T^2}/W$，$\sigma_{r4}=\sqrt{M^2+0.75T^2}/W$ |
| 单位载荷法 | $\Delta=\int M\bar M/(EI)\,dx$ |
| 图乘法 | $\Delta=\sum \omega\bar M_C/(EI)$ |
| 欧拉临界力 | $P_{cr}=\pi^2EI/(\mu l)^2$ |
| 柔度 | $\lambda=\mu l/i$，$i=\sqrt{I/A}$ |
| 冲击动荷系数 | $K_d=1+\sqrt{1+2h/\Delta_{st}}$ |

### 跨域陷阱

跨域共性陷阱（SI/CGS 混用、1/2 因子、单位遗漏等）见 `error_prevention.md` §0–§2。本模块**特有**的高频陷阱：

1. **单位混用**——材料力学最大的错误来源。截面给 mm、载荷给 kN，混出 N·mm 与 kN·m 差 10⁶ 倍。**要么全 m·N，要么全 mm·N**，并在答案里写明。
2. **惯性矩移轴**——组合截面必须先求形心，$I=I_c+Ad^2$；直接相加是错的。
3. **强度理论选错**——脆性/塑性与第一/第三理论的对应关系，选错则全题报废。
4. **欧拉公式越界**——柔度不判档就套欧拉，是压杆题的头号错误。
5. **静定结构算温度应力**——温度应力只在超静定中出现。
6. **图乘法用于曲线×曲线**——至少一个图必须直线。
7. **中间铰不拆**——铰处 $M=0$ 不会自动满足，必须拆段。

### 与工具配合的方式

- 静定梁的 N/Q/M/T 与截面几何、应力：交给 `mech_analyze`（若已安装 `dsh-mech-workbench`），它返回的 `checks` 可直接当 B 类证据引用。
- **静不定、压杆稳定、能量法、动载荷这四块工具明确不做**，必须手算 + 本模块协议，并如实声明未使用工具。
- 符号积分（挠曲线、莫尔积分）：环境可用时用 SymPy 复核一次；不可用则手算并声明。
