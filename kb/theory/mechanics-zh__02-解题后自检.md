## 三条老硬规则（仍然有效）

### 1. 截面积分 → 必须过整体量

$$\int_A\tau\,\mathrm dA=F_S,\qquad \int_A\sigma\,\mathrm dA=N,\qquad \int_Ay\sigma\,\mathrm dA=M$$

### 2. 分段刚度 → 必须建有限元

EI 沿杆长变化时，禁止手算 $\iint$ 求位移。梁单元刚度矩阵见下（第 7 题已用 4 单元复核 $8l^3/(3EI)$）：

```python
def kbeam(EI, Le):
    return EI/Le**3*np.array([[12,6*Le,-12,6*Le],[6*Le,4*Le*Le,-6*Le,2*Le*Le],
                              [-12,-6*Le,12,-6*Le],[6*Le,2*Le*Le,-6*Le,4*Le*Le]])
```

空间刚架直接用 PyNite（见 §5）。

### 3. 二力杆 / 桁架 → 必须先跑 `truss_solve`

先看各杆内力**比**，再谈临界力与截面配比。三节点两杆时两个支座都要设 `pin`。

## 四条新硬规则（v2）

### 4. 动力学题 → 必须先用 sympy 建一次 EOM

**触发**：任何"绕定点转动 / 求分离角 / 求约束反力"的题。

**禁止**直接手写牛顿-欧拉方程（我第 11 题就是 $\ddot\varphi$ 符号写反，得出"反力为负"的假矛盾）。

```python
phi = sp.Function('phi')(t)
T = sp.Rational(1,2)*J_O*sp.diff(phi,t)**2
V = 2*m*g*r*sp.cos(phi)
EL = sp.diff(sp.diff(T-V, sp.diff(phi,t)), t) - sp.diff(T-V, phi)   # = 0
```

**验收**：把解出的 $\omega^2$ 代回能量式，两边相等；反力表达式在 $\varphi\to0$ 时退化合理。

### 5. 框架稳定 → 先问"柱顶有没有剪力"

**禁止**给刚梁加力矩平衡（我第 9 题因此多算 1.5 倍）。
两柱同向侧移、柱内无剪力 ⇒ 每柱 $\mu=2$，载荷按静定分配，弱柱控制：

$$F_{\min}=2\cdot\frac{\pi^2EI_{\text{弱}}}{4l^2}$$

**自检**：若你的解比"弱柱单独临界 ×2"大很多，几乎一定多加了约束。

### 6. 力偶方向 → 切线矢量是弯曲，不是扭转

力偶矢量沿环的**切线**时，绕的是杆的**法向轴**（面外弯曲）；只有沿**杆轴**才是扭矩。
画图确认：切线矢量 ⊥ 杆轴 ⇒ 弯曲。（第 13 题我把切线当轴向，整题报废。）

### 7. 截面应力 → 先问是轴力、剪力还是环向薄膜力

- **横截面**上的应力 = 轴向合力/面积；闭合环管无端盖 ⇒ 轴力为零 ⇒ $\sigma_l=0$。
- **柱面纵截面**上的应力 = 环向薄膜力/壁厚，由半环平衡定。

## 工具模块（v2）

### sympy.physics.mechanics / 纯拉格朗日
动力学首选。`KanesMethod` 可做带约束的多体。

### PyNite（`pip install --no-deps` + 回锁 numpy）
3D 刚架/桁架/连续梁。导入名 **`Pynite`**（小写 n），`from Pynite import FEModel3D`；
`member.moment('Mz', x)`、**`member.torque(x)` 只收一个参数**。
第 10 题复核：$M_A=5\sqrt2m/18$、$T_B=2\sqrt2m/9$，与解析一致。

### 无现成库的两类
曲杆/圆环（用 sympy 做平面假设积分）、缠绕薄壁容器（半环平衡 + 协调手推）。

## 三个警报

1. 结果与直觉差一个量级以上 → 先怀疑自己。
2. 出现 1/32、1/1024 这类整齐系数 → 回头验整体量。
3. **只有单一方法得到的结果 → 必须补第二条路径。**
