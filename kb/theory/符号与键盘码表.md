# 符号与键盘码表（打不出希腊字母时怎么表示）

> 用途：竞赛现场赛题是**纸质**的，用户只能用键盘把题目打给 AI。
> 但**打不出希腊字母**（α β θ μ ω…），输入法翻页很慢，还常打错。
> 本表给出**纯 ASCII 的替代写法**，AI 按本表还原成标准符号。
>
> 关键词：符号怎么写、希腊字母怎么打、打不出、键盘、ASCII、缩写、表示法、输入

---

## 一、总规则

1. **希腊字母用完整英文单词**，不要用单字母缩写。
   - ✅ `theta` `omega` `sigma` `lambda` `mu`
   - ❌ `a`（会与长度 a 混）、`b`（与点 B 混）、`e`（与模量 E 混）、`t`（与时间/厚度 t 混）
2. **拉丁字母、题面给出的符号一律照抄**：`a b d l h R m F M k E I W b`。
3. **不需要打 LaTeX**。`\frac{a}{b}` 这种不用写，写 `a/b` 就行。
4. 大小写有意义：`R` 与 `r`、`F` 与 `f` 不通用，按题面写。

---

## 二、希腊字母对照

| 符号 | 这样打（推荐） | 也接受 | 常见用法 |
|---|---|---|---|
| α | `alpha` | — | 圆锥角、角加速度、比例 |
| β | `beta` | — | 角度、伸长比增量 |
| γ | `gamma` | — | 剪应变、重度 |
| δ | `delta` | — | 位移、壁厚、微小量 |
| Δ（大写） | `Delta` | `Del` | 增量、差值 |
| ε | `eps` | `epsilon` | 应变、角加速度 |
| ζ | `zeta` | — | 阻尼比 |
| η | `eta` | — | 效率、坐标 |
| θ | `theta` | `th` | 转角、极角、斜面倾角 |
| κ | `kappa` | — | 曲率 |
| λ | `lam` | `lambda` | 柔度、伸长比、波长 |
| μ | `mu` | — | 摩擦因数、泊松比 |
| ν | `nu` | — | 泊松比 |
| ξ | `xi` | — | 坐标、截面核心 |
| π | `pi` | — | 圆周率 |
| ρ | `rho` | — | 密度、曲率半径、极径 |
| σ | `sig` | `sigma` | 应力 |
| τ | `tau` | — | 切应力、时间常数 |
| φ | `phi` | `fy` | 角度、相位 |
| χ | `chi` | — | — |
| ψ | `psi` | `sy` | 转角、摆角 |
| ω | `omega` | — | 角速度 |
| Ω（大写） | `Omega` | — | 截面模量（极）、区域 |

**易混淆对，务必区分：**

| 不要混 | 正确写法 |
|---|---|
| 直径 `d` vs 增量 `Delta` | `d=20mm` ／ `Delta_l` |
| 质量 `m` vs 摩擦因数 `mu` | `m=2kg` ／ `mu=0.3` |
| 模量 `E` vs 应变 `eps` | `E=200GPa` ／ `eps=0.002` |
| 长度 `l` vs 柔度 `lam` | `l=1m` ／ `lam=80` |
| 半径 `R` vs 密度 `rho` | `R=100mm` ／ `rho=7800kg/m3` |

## 三、上下标与运算符

| 含义 | 这样打 | 例 |
|---|---|---|
| 下标 | 直接跟数字，或 `_` | `q1` `q2` `E1` `sig_max` `lam_r` |
| 上标 / 幂 | `^` | `R^2` `10^3` `m/s^2` `^-1` |
| 根号 | `sqrt(...)` | `sqrt(3)` `sqrt(2*g*h)` |
| 分式 | `/` | `1/2*m*v^2`、`F/A` |
| 乘 | `*` 或空格 | `2*m` |
| 角度 | `deg` | `30deg` `theta=45deg` |
| 不等号 | `<=` `>=` `!=` `~=` | `theta<=90deg` |
| 趋于 / 方向 | `->` | `t->0`、`F->down`、`F->right` |
| 正比 | `prop` | `sig prop 1/r` |
| 求和 / 积分 | `sum` / `int` | `sum(F)=0`、`int(0,l)` |
| 矢量 | 分量写括号 | `v=(vx,vy)`、`F=(0,-P)` |
| 一点/二点导数 | `d/dt` / `d2/dt2` | `d(theta)/dt` |
| 偏导 | `pd` | `pd(U)/pd(x)` |
| 绝对值 | `abs(...)` | `abs(v)` |
| 约等于 / 大小 | `~=` / `|F|` | `|F|=10kN` |

## 四、单位与量纲

- **单位照写不翻译**：`mm` `cm` `m` `kN` `N` `MPa` `GPa` `kg` `s` `rad/s` `deg` `N*m` `mm2` `mm3` `mm4`
- 平方/立方：`mm2` `mm3` `mm4`（或 `mm^2`）
- 科学计数：`12.8e3`、`1e6`
- **量级必须带**：写 `90kN` 不要只写 `90`；写 `0.3mm` 不要只写 `0.3`

## 五、完整例子（现场就这样打）

```
T5 15fen
结构: 圆盘O + 连杆AB + 活塞B, 铅垂面内
已知: OA=1000mm, AB=2000mm
      AB m=200kg, 活塞B m=200kg
      omega=100rad/s 逆时针 匀角速, 驱动力F作用在活塞上
图: O在左(圆盘心), A在盘边缘, AB是连杆, B是活塞(水平导轨上)
    theta 是 OA 与水平线的夹角
求: (1)刚体模型, theta=?时F有多解; theta=90deg求F
    (2)AB当变形体, A=12.8e3mm2, W=1e6mm3, [sig]=180MPa
       theta=90deg校核强度 + 画弯矩图形状
缺: theta的起始边(水平还是竖直)? B的导轨是否水平?
```

**要点：**

- 第一行 `T5 15fen` 给题号与分值 → AI 能立刻排优先级
- `结构:` `已知:` `图:` `求:` `缺:` 五个标签固定，AI 按标签解析
- **`缺:` 那一行最重要**——主动写出你读不准的地方，AI 就不会编

## 六、原文符号丢失时怎么问

赛题文字若来自 OCR 或有缺损（例如「ABC 的角速度为」后面符号没了），**不要自己猜**，直接标注：

```
原文: "ABC 的角速度为" ← 这里缺符号，我判断是 omega(角速度)，对吗？
原文: "系统在 45 的位置平衡" ← 我判断是 phi=45deg，对吗？
```

**规则：凡是原文里"该有符号却没有"的地方，必须显式写出你的猜测并请 AI 确认，不要静默补。**

## 七、必须问清的六类（历届失分都在这）

| # | 问什么 | 为什么致命 |
|---|---|---|
| 1 | **构件相对位置**（谁左谁右、谁上谁下、谁和谁固结/铰接） | 定了几何关系，错了整题作废 |
| 2 | **角度基准**（θ 与水平还是竖直？起点在哪条边？） | 三角函数的正负与角度值全反 |
| 3 | **支座类型**（固支/铰支/滚动/弹簧/自由） | 决定约束方程个数；铰支常画成端部**空心小圆圈** |
| 4 | **接触性质**（光滑/有摩擦、碰撞是弹性还是塑性、是否分离） | 决定有没有摩擦力和能量损失 |
| 5 | **分步题条件继承**（这一问还继承上一问的什么？什么已消失？） | 一处错整个小问归零 |
| 6 | **正方向与符号约定**（x、y 朝哪；转角逆时针为正还是顺时针） | 与题面图不一致时全部符号反号 |

## 八、画图时的标签写法

`scripts/draw_figure.py` 的 `label` **直接用 ASCII**，不需要希腊字母：

| 想显示 | label 写 |
|---|---|
| q₁ | `q1` |
| σ_max | `sig_max` 或 `$\\sigma_{max}$` |
| θ | `theta` 或 `$\\theta$` |
| λ_r | `lam_r` |
| Δβ | `Delta_beta` |

普通数字、拉丁字母、中文直接可显示；希腊字母若要真切显示，用 mathtext `$...$`。

## 九、录入模板：九行版 / 五行版

**九行版**——第一题、复杂题用。打字约 3~4 分钟。

```
【题号】第 X 题，共 XX 分
【题型】静力 / 运动 / 动力 / 材力 / 稳定
【已知】
【支座】
【载荷】
【坐标系】
【待求】
【图形状】
【缺】
```

**五行版**——熟练后、时间紧时用。

```
T1 15分 动力
已知：边L；三角柱m、形心O1、J=?；半圆柱EF=L不计质量；杆AD长13L/5、m；A铰接
图：三角在左A在上，杆A→右下D触地，半圆柱夹在杆与地面间、EF贴杆、H触地
缺：J=？ M转向？
求：(1)D支撑力为零求M (2)...
```

**只有两行绝对不能省：**

| 行 | 为什么 |
|---|---|
| **【图形状】/ 图** | 所有"画错"都出在这行。不用画，用"谁在哪、朝哪、谁碰谁的哪部分"说清 |
| **【缺】** | 主动交底。看到"缺"我就知道哪些必须问、哪些可以按你写的走 |

**【坐标系】可省**——不写就默认 x 向右、y 向上、转角逆时针为正。

## 十、九行版填好的样子（15 届第 1 题）

```
【题号】第1题，共15分
【题型】动力（机构+动力学）
【已知】等边三角形ABC边长L；弧AB/BC/CA的圆心分别是C/A/B（莱洛三角）
        弧边三角柱质量m、质心在形心O1、绕O1转动惯量J=？
        半圆柱EHF直径EF=L，不计质量
        杆AD质量m、长13L/5；A端铰接在三角柱顶点A
【支座】三角柱：水平面纯滚动；半圆柱：H点触地纯滚动
        A：铰接；D：接触地面
【载荷】力偶M作用在三角柱上；有重力
【坐标系】x向右、y向上；逆时针为正
【待求】(1)平衡且D支撑力为零求M (2)瞬时静止求alpha2 (3)...
【图形状】三角柱在左，A在正上方离地L，弧BC贴地，B、C在左右两侧
        杆AD从A向右下、D触地
        半圆柱的平边EF与杆共线（贴在杆下侧）、E、F悬空
        弧在H点触地，H在O2正下方
【缺】J的具体值；力偶M正转还是反转；(2)(3)的问句
```

> 对比一下：如果当时【图形状】这么写了，我就不会把半圆柱画成"平边贴地、弧朝上"。
> **这九行的全部意义，就是把"我以为是常识"的地方逼着写出来。**
