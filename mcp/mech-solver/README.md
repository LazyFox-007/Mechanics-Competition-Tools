# mech-solver —— 补齐四个空白分支

> 覆盖评估的结论是"工具覆盖不全，知识覆盖接近全"。这个服务补的就是**工具**那一半：
> 四个高频、标准化、容易算错、且**能自动校核**的分支。

## 为什么是这四个

| 分支 | 补之前 | 补之后 |
|---|---|---|
| 能量法 | 只能手推积分 | `energy_method`：卡氏定理 / 单位载荷，通用积分器 |
| 桁架 | 节点法手算，最易漏杆/记错号 | `truss_solve`：整体线性求解 + 逐节点平衡自校验 |
| 刚体平面运动 | **完全空白** | `rigid_planar`：基点法速度/加速度、速度瞬心 |
| 压杆稳定 | 只能套公式手算 | `buckling_solve`：柔度分档 + 欧拉/经验公式 |

**碰撞不做**：几何依赖太强，通用化性价比最低（评估里也是这个结论）。

## 工具

| 工具 | 输入 | 输出 | 自带校核 |
|---|---|---|---|
| `energy_method` | `op=castigliano`：M(x)、EI、区间、载荷符号 P | U、δ=∂U/∂P | 符号导数 vs 数值中心差分 |
| | `op=unit_load`：M(x)、m̄(x)、EI | δ=∫M·m̄/(EI)dx | 与闭式解对照（用例里两边都算） |
| `truss_solve` | 节点、杆件、支座、载荷 | 杆力（拉正压负）、反力、零杆 | 逐节点 ΣF=0 残差；超静定/机构直接拒绝 |
| `rigid_planar` | `op=vel/acc/ic`、ω、α、vA、aA、矢径 r | vB / aB（含法向项）/ 速度瞬心 | \|v\|=ω·r 一致性 |
| `buckling_solve` | E、I、A、l、两端约束、σp（可选）、a/b（可选） | μ、λ、σcr、Pcr、柔度档位 | σcr·A 与 Pcr 一致 |

## 边界

1. **只解静定桁架**：$m+r-2N\neq0$ 时直接拒绝，不给最小二乘的假解
2. `energy_method` 只做**等截面、静定**梁：变截面请分段；超静定需先解多余约束力
3. `rigid_planar` 是**公式助手**，不建模：约束（纯滚动、绳长、铰接）要你自己写出位移关系
4. `buckling_solve` 只给临界力，**不给安全系数**；经验公式的 a/b 由用户提供（各材料不同）
5. 不做碰撞、塑性、大变形、稳定以外的一般非线性
