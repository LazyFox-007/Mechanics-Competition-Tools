## 规则 1　截面积分必须过整体量

**凡是**对截面/体积做积分求合力（正应力合力、剪应力合力、惯性矩、静矩、形心），
**必须**同时验证至少一个整体量：

$$\int_A \tau\,\mathrm dA = F_S,\qquad
\int_A \sigma\,\mathrm dA = N,\qquad
\int_A y\,\sigma\,\mathrm dA = M$$

只要有一条对不上，积分表达式就是错的。

```python
import numpy as np
y = np.linspace(-h/2, h/2, 200001)
# 你的 tau(y) 表达式
tau = ...                                    # ← 被检验的对象
print(np.trapz(tau*b, y) / F_S)              # 必须等于 1.0000
```

### 真实反例（第十四届 第 3 题 (1)）

- 我写的静矩： $S^*=\dfrac{b}{2}\left(\dfrac{h}{2}-y\right)^2$ ❌
- 正确： $S^*=\dfrac{b}{2}\left(\dfrac{h^2}{4}-y^2\right)$
- 后果：底部 $h/4$ 条带的剪应力合力从 $5F_S/32$ 变成 $F_S/32$，整题答案作废
- 检验结果： $\int\tau\,\mathrm dA/F_S = \mathbf{2.0000}$（应为 1）——**一行代码**

## 规则 2　分段刚度必须建有限元，禁止手算积分

**凡是** EI / EA 沿杆长分段变化，或杆系由多段不同截面组成，
**禁止**手算 $\iint$ 求位移与转角，直接建 3–4 个梁单元的有限元。

只有 10 行，且**已经写过、可复用**：

```python
def kbeam(EI, Le):
    return EI/Le**3*np.array([
        [ 12,   6*Le,  -12,   6*Le],
        [6*Le, 4*Le*Le, -6*Le, 2*Le*Le],
        [-12,  -6*Le,   12,  -6*Le],
        [6*Le, 2*Le*Le, -6*Le, 4*Le*Le]])
```

### 真实反例（第十四届 第 5 题 (1)）

- 我算：$w_C=4.58$ m，$\theta_C=22.9$ rad
- 官方：$w_C=48.053$ mm，$\theta_C=0.107$ rad
- 原因：C 点的挠度取决于 **A→C** 区间的曲率，我只对 **C→D** 段积分（把 C 当成了固定端）
- 有限元三单元：`w_C = 48.027 mm, θ_C = 0.1070 rad` —— 30 秒复现官方答案

## 规则 3　二力杆 / 桁架必须跑 `truss_solve`

**凡是**遇到二力杆支架、桁架、杆系，先让工具给出各杆内力，**再**谈临界力与配比。

```json
mcp__mech-solver__truss_solve(nodes, members, supports, loads)
```

注意：三个节点两根杆时，两个支座都要设 `pin`，否则报"几何可变（m+r−2N = −1）"。

### 真实反例（第十四届 第 4 题 (3)）

- 我写：让两杆临界力相等 ⇒ $I_{AB}/I_{AH}=(L_{AB}/L_{AH})^2=3.0$
- 官方：$I_{AB}/I_{AH}=\sqrt3=1.732$
- 原因：**忘了载荷是按几何分配的**，$N_{AH}/N_{AB}=\sqrt3$，不是 1:1
- `truss_solve` 一次调用给出：`B-A: −13584.8 N`，`A-H: −23529.2 N`，比值 **1.7320**

## 工具查不出的：建模漏项

第 6 题我少了一个因子 2、力偶符号也反了。这类错误**工具救不了**——
我提供的模型本身就缺项，工具忠实按错模型算，算得再准也是错的。

只能靠这四类物理自检：

| 手段 | 判据 |
|---|---|
| **能量法交叉验证** | 用动能/势能另推一遍，与牛顿-欧拉结果比对 |
| **极限情形** | $y\to0$、$\alpha\to0$、$k\to0$、$\theta\to0$ 时是否退化为已知解 |
| **量纲与量级** | 系数是否无量纲、数量级是否合理 |
| **对称性** | 对称结构在对称载荷下的内力/位移是否对称 |


## 三条"看起来对"的警报

1. **结果与直觉差一个数量级以上** → 先怀疑自己。第十四届第 5 题 4.58 m 的挠度就是警报，我按了静音。
2. **中间量出现 1/32、1/1024 这类过于整齐的系数** → 立刻对照整体量（规则 1）。这类系数往往来自漏了某个因子。
3. **只用了单一方法** → 必须补第二条路径。手推"看起来顺"不代表对。

---

## 一句话总结

> **能算 ≠ 算对。**
> 每次给出一个解析表达式，都要有一条**不依赖同一套推导**的路径去核对它。
> 工具的价值不在于替你算，而在于**它不会跟着你一起错**。
