# 赛规摘要（AI-MECH-2026-001）

> 来源：《"国产AI大模型辅助理论力学与材料力学解题"赛题规则》附件2，共 3 页。
> 原文以组委会最新通知为准，这里只做要点提炼与合规提醒。

---

## 一、任务形态

- 理论力学与材料力学**混合题包**，各占约 50%
- 题型：填空题、计算题、证明题、结构简图题、小型综合建模题
- 每题必须输出：**最终答案 + 关键公式 + 主要推导步骤 + 受力/变形示意说明 + 单位与量纲检查 + 校核结论**
- 「仅给最终结果而无可追溯过程者，过程分从严计」

## 二、范围

**理论力学**：静力学受力分析、平面/空间力系平衡、摩擦、重心与形心；运动学点的合成、刚体平面运动；动力学质点/质点系、动量定理、动量矩定理、动能定理、达朗贝尔原理、虚位移与振动基础。

**材料力学**：轴向拉压、剪切与挤压、扭转、弯曲内力/应力/变形、应力应变状态与强度理论、组合变形、压杆稳定、能量法基础、动载荷与交变应力初步。

## 三、硬约束（违反即取消成绩）

| # | 要求 | 原文要点 |
|---|---|---|
| 1 | **模型** | 必须国产 AI 大模型，须本地化或指定评测环境部署；**禁止调用境外闭源生成式 API** |
| 2 | **禁止联网** | 禁题库爬取、人工场外求助、**远程实时助攻** |
| 3 | **知识库 ≤ 200 MB** | 以解压后、**含检索索引、配置和元数据**的总量计 |
| 4 | **知识库内容白名单** | 仅限：公式表、符号约定、教材例题、常数表、自研笔记、合规开源资料 |
| 5 | **知识库黑名单** | 严禁夹带**当次赛题、答案、测试标签或网络题解** |
| 6 | **须提交知识库清单** | 文件清单（复现包还要求哈希） |
| 7 | **留痕** | 模型信息、版本号、部署配置、prompt 模板、检索注入片段、推理日志、最终答案全链路；组委会可复现、抽检、溯源 |

## 四、流程与形式

| 轮次 | 形式 | 要点 |
|---|---|---|
| 初赛 | 客观机评为主 | 用国产模型解**组委会公布的赛题**，任选 **3 道**，按指定格式提交**技术报告（≤2 页）** |
| 复赛 | 线下集中 | 现场解题，**全程录制** + 过程一致性检查；可自带合规解题资源 |
| 总决赛 | 路演答辩 | 详见后续通知 |

## 五、评分与排名

```
总分 = 答案正确性 70% + 过程与公式规范 20% + 表达/量纲/校核 10%
```

**同分排序**：Token 少 → 总推理用时短 → 平均每题 Token 少 → 综合题得分高 → 加试。

**Token 计量口径**（重要）：
- 计入：系统提示 + 用户题干 + 知识库检索注入 + 模型输入输出 + **多轮重试与自检**
- 命中缓存**不核减**
- **重跑和尝试都计入**

> 推论：工具描述、技能全文、检索片段都在烧 Token。
> 「多装工具」这件事在赛场上是有代价的，只留当前题需要的。

## 六、提交材料

1. **答案文件** —— `teamName_round_problemID_answer` 命名，压缩包内不得嵌套无关目录
2. **过程日志** —— prompt、检索片段、关键中间结果、报错与重试记录
3. **复现包** —— 模型部署说明、模型信息、知识库清单与哈希、`requirements.txt`、`README.md`
4. **技术报告** —— 初赛/复赛 ≤ 2 页：架构、知识库构造、Token 控制策略、解题思路
5. 答辩材料：初赛/复赛无需 PPT

## 七、违规红线

夹带赛题答案 · 调用境外 API · **联网检索** · 篡改日志 · 泄露测试题 · 抄袭或共享解题链路
→ 取消当轮成绩，情节严重取消参赛资格。

## 赛前自检清单

- [ ] 模型是国产、已本地/指定环境部署，**无境外 API 调用**
- [ ] 所有联网 MCP 已 `disabled: true`（`browser`、`context7`）
- [ ] 知识库解压后总量 ≤ 200 MB，且**不含任何赛题/答案/题解**
- [ ] 知识库文件清单已导出（含哈希更稳妥）
- [ ] prompt 模板、检索片段、推理日志已开始留痕
- [ ] 计时与 Token 统计方式已确认（重试也计入）
- [ ] 复现包里有 `requirements.txt` 与 `README.md`
