# 工具映射：赛题类型 → 该调什么

按「总分 = 答案 70% + 过程 20% + 表达/校核 10%」倒推：**得分点不只在答案，还在过程和校核**。
下表每行都标了能拿哪一段分。

---

## 一、读题

| 场景 | 工具 | 说明 |
|---|---|---|
| 赛题是 PDF | `mcp__document__pdf_text` | 直接出文字；扫描件用 `pdf_render` 转图 |
| 题图看不清（受力图、尺寸标注） | `mcp__document__pdf_render` → `read_image` | 150–200 dpi 够看清箭头和标注 |
| 整页排版复杂 | 插件 `mech_read_problem` | 17 种预处理算子 + 可选二次视觉转写 |
| 读完要复核 | 插件 `mech_verify_reading` | 把转写渲染回去和原图并排 |

> **得分点**：读错一个数整题报废。这一步花多少时间都值。

---

## 二、理论力学

| 题型 | 主力 | 辅助 |
|---|---|---|
| 静力学受力分析、桁架、摩擦、重心 | `undergrad-physics-skill` 牛顿模块 | `mcp__sympy__*` 解约束方程 |
| 平面/空间力系平衡 | `mcp__sympy__solve_linear_system` | 技能里的 F 量纲检查 |
| 运动学（点的合成、刚体平面运动） | 技能 + 手推 | sympy 做速度/加速度合成验证 |
| 动力学三大定理 | `mcp__sympy__*`（积分、微分） | 技能里的 C 守恒量校验 |
| 拉格朗日 / 达朗贝尔 / 虚位移 | sympy 求偏导、化简 | 技能里的 I 独立方法（牛顿重解） |
| 振动基础 | `mcp__sympy__matrix_eigenvalues` | 特征值回代（J 一致性） |

## 三、材料力学

| 题型 | 主力 | 辅助 |
|---|---|---|
| 拉压、剪切挤压 | sympy 手算 | 插件的应力校核 |
| 扭转 | sympy | — |
| **弯曲内力（N/Q/M/T）** | **插件 `mech_analyze` + `mech_diagram`** | 自动出图 + `checks` 直接当校核证据 |
| 弯曲应力、变形（挠曲线） | `mcp__sympy__dsolve_ode` 解 EI·v''=M | 插件截面几何 |
| 应力状态、强度理论、莫尔圆 | 插件 `mech_diagram` 的 mohr 预设 | sympy 特征值复核主应力 |
| 组合变形 | sympy 叠加 | — |
| **压杆稳定** | ❌ 插件不支持，**手推欧拉/经验公式** | sympy 算柔度 λ |
| **能量法（卡氏/单位载荷）** | ❌ 插件不支持，手推积分 | sympy 做积分 |
| **静不定** | ❌ 插件不支持，力法手推 | sympy 解协调方程 |
| 动载荷 / 交变应力 | ❌ 插件不支持 | — |

> ⚠️ 四个 ❌ 恰好是提高题高频区。插件在这四块会明确返回 `determinate: false` 或 `unsupported`，
> **它不猜结果是对的**——但这意味着这四类题必须靠 skill 的流程 + sympy 手推。

## 四、验算：过程分和校核分的主要来源

`undergrad-physics-skill` 定义了 8 种方法，标准题通常取「F + B + 一个独立检查」：

| 代号 | 方法 | 什么时候必用 |
|---|---|---|
| **F** | 量纲检查 | 几乎每题（表达分 10%） |
| **B** | 回代（代回原方程） | 解出表达式后 |
| L | 极限/特例 | 结果有物理直觉可对照时 |
| C | 守恒量 | 动力学、能量法 |
| D | 定义域/参数域 | 有摩擦、有根号、有频率时 |
| E | 数值抽样 | 复杂表达式 |
| I | 独立方法（牛顿 vs 拉格朗日） | 高风险题 |
| J | 一致性（迹/行列式/特征值回代） | 矩阵、主应力、小振动 |

**输出时必须附一行验算摘要**，例如：

```
验算：①F 量纲 ②B 回代 ③L 极限(ω→0 退化为单摆)，FAIL 0 项
```

这行字本身就是「过程与公式规范」的得分证据。

## 六、赛时不要碰的工具

| 工具 | 原因 |
|---|---|
| `mcp__browser__*` | 联网检索 → 违规 |
| `mcp__context7__*` | 联网拉文档 → 违规 |
| `mcp__everything__*` | 本身不联网，但赛时无用，白占工具描述 Token |
| `mcp__video__*` / `mcp__image__*` / `mcp__eac__*` | 与解题无关，纯烧 Token |

> Token 计入排名且**重试也计入**。赛前把无关 MCP 全部 `disabled: true`。
