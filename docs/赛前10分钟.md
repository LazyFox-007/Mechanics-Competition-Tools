# 赛前 10 分钟：把工具链配好并验完

> 目标：从"克隆下来"到"确认能用"，**两条命令 + 一次重启**，全程 ≤ 10 分钟。
> 遇到任何异常都能一条命令回滚。

---

## 0. 前提（一次性）

| 需要 | 检查命令 | 没有会怎样 |
|---|---|---|
| Python ≥ 3.10（带 sympy） | `python -c "import sympy;print(sympy.__version__)"` | sympy / mech-io 起不来 |
| Python 依赖 | `pwsh -File setup.ps1 -InstallDeps` | 同上 |
| Node（`dsh` CLI） | `dsh --version` | 装不了插件、`dsh` 命令不可用 |
| DSH 桌面端已登录 | 打开一次 | — |

> 这四样缺任何一个，`-Verify` 都会红字指出来，不用猜。

---

## 1. 配（约 5 秒）

```powershell
git clone https://gitee.com/haveink/mechanics-competition-tools.git
cd mechanics-competition-tools
pwsh -File setup.ps1 -Competition
```

`-Competition` 会做四件事：

1. 复制 4 套技能到 `~/.dsh/skills`
2. 注册 4 个 MCP：`document` / `sympy` / `sympy-physics` / `mech-io`
3. **把其余 MCP 全部 disabled**（`browser`/`context7` 属于赛规禁止的联网工具；
   `everything`/`video`/`image`/`tools`/`eac`/`rea` 只是白占上下文）
4. 改配置前自动备份，写完用 YAML 校验

> 也可以直接双击 `setup.cmd`，选 1。

**幂等**：重复跑不会重复注册；已经是对的就报"无需改动"。

---

## 2. 重启 DSH（约 20 秒）

MCP 子进程在配置加载时启动，**不重启不生效**。

重启后如果 `execution` 类工具还在报错，先看第 4 节。

---

## 3. 验（约 5 秒）

```powershell
pwsh -File setup.ps1 -Verify
```

它不是"读配置说有"，而是**把每个 MCP 真的拉起来**，走 `initialize` + `tools/list`。期望输出：

```
  [OK  ] document         10 工具  ( 97 ms)
  [OK  ] sympy            32 工具  (1276 ms)
  [OK  ] sympy-physics     7 工具  ( 524 ms)
  [OK  ] mech-io          11 工具  ( 572 ms)
  —— 环境 ——
  [OK] 技能 mechanics-map / mechanics-zh / undergrad-physics-skill / math-skill
  [OK] 插件 dsh-mech-workbench
  [OK] 依赖 sympy / numpy / matplotlib / PIL / fitz
  结论：全部就绪
```

任何一项红字都是**确定性问题**，不是玄学。

---

## 4. 插件（唯一装不了的一步）

插件是 Host-only bundle，脚本装不了。**两步**：

```powershell
# 第一步：装（会用 profile 的 pnpm，本质是 link 到本仓库）
dsh plugin --profile desktop add "D:\path\to\mechanics-competition-tools\plugins\dsh-mech-workbench"
```

第二步：重启 DSH，确认工具列表里出现 `mech_analyze` / `mech_diagram` 等 9 个工具。

> 也可以用图形界面：设置 → Agent 预设 → 创造入口 → `plugin_manager install_bundle`。
> 装完 `-Verify` 会显示"插件 dsh-mech-workbench [OK]"。
>
> **注意**：`plugins/dsh-mech-workbench/package.json` 必须**无 BOM**。带 BOM 时
> DSH 解析 JSON 直接失败，报 `Unexpected token`——这是踩过的坑。

---

## 5. 回滚（30 秒）

```powershell
pwsh -File setup.ps1 -Restore          # 回到最近一次备份
pwsh -File setup.ps1 -Restore -BackupPath "C:\Users\你\.dsh\cordis.patch.yml.bak-switch-20261028-184500"
```

也可以直接改回来：

```powershell
python scripts/mcp_switch.py --enable browser,context7
python scripts/mcp_switch.py --list      # ON/OFF 一眼看清
```

---

## 6. 赛中止损清单

| 症状 | 处置 |
|---|---|
| DSH 起不来 | `setup.ps1 -Restore`；仍不行就把插件删掉（`dsh plugin --profile desktop remove dsh-mech-workbench`） |
| 某个 MCP 报 `spawn ENOENT` | `-Verify` 会指出是哪个；改 `cordis.patch.yml` 里的 `command` 为 `D:\anaconda\python.exe` |
| 工具调不通但配置在 | 先 `-Verify` 看服务能不能单独起来：能 → DSH 侧问题（重启）；不能 → 看报错 |
| 中文报 `UnicodeEncodeError` | 用 `mech-io` 的 `py_run`，别走 shell |
| 时间不够 | 只留 `mech-io` + `sympy` 两个也能解题（裁图、跑脚本、符号推导都在） |

---

## 7. 三档配置，按时间挑

| 档位 | 命令 | 时间 | 工具数 |
|---|---|---|---|
| 全自动 | `setup.ps1 -Competition` + 重启 + `-Verify` | ~1 分钟 | 60（4+7+11+32+插件 9） |
| 跳过插件 | 同上，不装插件 | ~1 分钟 | 51 |
| 最小 | 只留 `mech-io`：`mcp_switch.py --only mech-io` | ~40 秒 | 11 |

> Token 计入排名且重试也计入。**能少开就少开**，第 2 档往往是最优。
