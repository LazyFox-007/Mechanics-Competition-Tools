# 建模决策卡 —— 为什么加这个工具

> 一句话：**求解器再准，也按你给的模型算。**
> 第十四届实测证明，丢分最重的地方不在"算错"，而在"没问自己一句话"。

---

## 一、实测归因（第十四届，120 分）

答案口径 **93 分（77.5%）**，评分细则口径 **82 分（68.3%）**。27 分失分拆开：

| 失分 | 分值 | 性质 | 有工具能抓吗 |
|---|---|---|---|
| 第 6 题（轮对） | −17 | **建模轴沉默默认** | 现有工具：**不能** |
| 第 5 题(2) 椭圆积分闭式 | −7 | 形式化能力 | 缺专用工具 |
| 第 1 题 无受力图 | −6 | 交付形式 | 有 `mech_diagram`，但没加载 |
| 第 3 题(3) 缺 $x_0$、$y_2$ | −4 | 形式化能力 | 缺 |
| 第 4 题 四舍五入 | −1 | — | — |

第 6 题的两条错，全是**没被问出口的问题**：

| 建模轴 | 我走了什么默认 | 正解 | 教训 |
|---|---|---|---|
| 锥面滚动半径沿横向的梯度方向 | 「向外增大」 | **向辋内（法兰侧）增大** | 一个符号 → 纵向蠕滑 → 横摆耦合项全反 |
| 轮对轴线能否绕纵向轴倾斜 | 「假定始终水平」 | **必然倾斜**（两轮半径不等） | 漏一个自由度 → 侧向力系数少一个因子 |

这两条都不是算力问题。`solve_bvp` 想得再对，模型给错了它只会忠实地算错。

## 二、为什么不做"自动建模"

讨论过三种形态：

| 形态 | 评价 |
|---|---|
| 2^N 枚举所有可能模型让人选 | **否**。轮对那道题至少 8 条决策轴，256 套方程，人选不过来 |
| AI 自动选模型 | **否**。赛规要求可复现可留痕，模型自己拍板无法追溯 |
| **活决策轴清单 + 矛盾检查** | **是**。只列题干没钉死的轴，逼每条有 evidence |

它的定位不是"帮你建模"，是**不让你偷偷假设**。

## 三、工具

见 `mcp/mech-model/`。一个工具 `model_card`，四个 action：

```
index  → 列题型
probe  → 按题干关键词给候选
list   → 给该题型的活决策轴（选项 / 选错后果 / 判别试验）
check  → 收 decisions，返回 MISSING / UNARGUED / BAD_VALUE / CONTRADICTS_STEM / CONFLICT
```

**铁律：`evidence` 为空或 `assumed` 一律判 block。**

`check` 返回的 `filled` 就是留痕要求里的「建模声明」，可直接贴进过程日志。

## 五、体积与 Token 账

赛规 Token 计量包含**系统提示**，工具描述每轮重复计费。

| 方案 | 每轮 Token | 说明 |
|---|---|---|
| 4 个独立工具 | ≈1000 | 原设想 |
| 1 工具 + 4 action | **≈120** | 实采（描述 244 字符） |

按 50 轮估算：省约 4.4 万 token。

代码 + 卡合计约 25 KB，无第三方依赖，赛规下按「自研笔记」计入知识库，远低于 200 MB。

# 七、v0.2.0：按第十五届实测再改一轮

第十五届提高题做完只有 **39/60**，第 6 题 12/30。复盘后发现两件事，直接改了卡库。

## 7.1 新增两张通用轴（这两条是本次最大的收获）

| 轴 | 为什么加 | 挡住哪一错 |
|---|---|---|
| **`figure_transcribed`** | 只要声明「只看过整页 / 凭印象」就判 **block** | 第十五届把压杆端部的**空心小圆圈（铰支）**读成固支 → 长度系数 1.0 变 0.7 → 临界力差 2 倍 |
| **`staged_condition`** | 分步题必须逐问写继承关系 | 第三问以为第一问的 $P$ 不再作用 → 该问归零 |

`figure_transcribed` 的来历值得记：补完卡我才去数，两轮 6 个错里有 **2 个是纯读图**，
而仓库自己就有 `problem-image-reading` 技能写明「小字读不清 → zoom，这是最有用的一步」，
我一次都没用。这条轴就是把那句散文变成硬门禁。

## 7.2 新增三张题型卡

| 卡 | 覆盖 | 来自 |
|---|---|---|
| `floating_stability` | 浮体静力稳定 + 刚体微幅振动 | 第十五届第 5 题（30 分）——原来 6 张卡里**一张都不匹配** |
| `sliding_block_on_beam` | 滑块在变形梁上滑动 | 第十五届第 6 题：(2) 判据选错、(3) 条件没继承 |
| `column_buckling` | 压杆稳定：端部约束 → 长度系数 | 第十五届第 6 题：$\mu$ 取 0.7 而官方取 1.0 |

## 7.3 回归靶子换成真实错题

原来的 20 项用例是我自己编的。现在换成**两次实测真实犯过的错**：

| 靶 | 期望 | 结果 |
|---|---|---|
| 第十四届第 6 题（锥度方向 + 轴线倾斜） | block，≥4 错 | block，4 错 |
| 第十五届第 6 题（判据 + 惯性力 + 条件继承） | block，≥5 错 | block，5 错 |
| 第十五届第 6 题（压杆把铰支读成固支） | block，报「空心圆=铰支」 | 命中 |
| 第十五届第 5 题（质心取界面 + BM 的 I 取错） | block | block，3 错 |
| 9 张卡的正确声明 | **全部 pass** | 9/9 pass |
| probe 命中 4 个新题型 | 全部命中 | 4/4 |

**PASS 55 / FAIL 0。**

## 7.4 配套改动

- `core.py` 的卡缓存改成**按 mtime 失效** —— 改 `cards.json` 不必重启 MCP。
- `scripts/preflight.py` 加两项：**卡库泄漏扫描**（不许出现 3 位以上小数、不许出现历届答案数值）、**插件是否已装**（给出 `install_bundle` 的完整指令）。
- `README` 的硬规则从「交卷前 4 条」重构成 **「求解前 4 条 + 交卷前 3 条」**——因为 35 分失分几乎全在求解前。

## 7.5 仍然没解决的

- 卡只能让我**不偷偷假设**，不能让我**假设对**。`sliding_block_on_beam` 的 `stop_criterion` 现在会拦住「准静态」，但拦不住「我选准静态并且硬说理由充分」。
- `column_buckling` 的 `end_condition` 依赖我如实填 `figure_transcribed`。如果我没放大却填了「已确认」，卡不会发现。
- 真正的补强是**把读图变成强制动作**（`img_crop` 放大 + 逐项转写），而不是再加卡。插件 `dsh-mech-workbench` 的 `mech_read_problem`（17 种算子 + 可选二次转写）就是干这个的，1.2 MB，但需创造模式安装。

# 八、v0.3.0：把 30 张题型判据卡转成决策卡（9 → 31）

## 8.1 起因

一直以为"题型覆盖不够"要靠**归纳**：从 75~85 道历年真题里抽决策轴。查了社区
（`memory` / `sequential-thinking` / TaxonomyBuilder 等），结论是**这些工具解决的不是这个问题**——
聚类能把相似题分堆，分不出"锥度朝哪边"这种轴；轴的价值全在 `if_wrong` 后果链，只能人写。

真正的问题不是缺归纳能力，而是：**仓库里已经有一份现成的分类体系，但没被用起来。**

`skills/mechanics-zh/modules/04-题型判据卡.md`，7.4 KB，**30 张题型卡**分 5 大类
（静力学 6 / 运动学 4 / 动力学 6 / 材料力学 11 / 通用 3），每张已是四段式：
**识别 / 第一步 / 坑 / 校核**。它跟 `cards.json` 的 schema 几乎一一对应：

| 判据卡 | → | cards.json |
|---|---|---|
| 识别 | → | `triggers` |
| 坑（每张 1–2 条） | → | `axes` |
| 校核 | → | `axes[].test` |
| 第一步 | → | 丢弃（解题配方，不是轴） |

## 8.2 做了什么

去掉已被现有 9 张卡覆盖的，**新增 22 张**：

- 静力学：`spatial_force_system` / `truss_zero_bar` / `friction_angle_geometry` / `centroid` / `determinacy`
- 运动学：`coriolis_motion` / `instant_center` / `pure_rolling` / `rotating_frame`
- 动力学：`angular_momentum` / `work_energy` / `impact` / `d_alembert` / `virtual_work` / `two_stage_motion`
- 材料力学：`axial_indeterminate` / `torsion` / `beam_internal_forces` / `beam_deflection` / `combined_loading` / `energy_method` / `thin_wall_vessel`

每条「坑」补两样原卡没有的东西：

1. **`if_wrong`**：写清"选错会翻哪个量、差几倍"，不是"会错"
2. **`test`**：能用图或极限做完的操作（如"d→0 时退化为实心公式"、"ω=0 时科氏为零"）

另外把踩过的三个静默错误写进对应的卡：

| 静默错误 | 落在哪张卡 |
|---|---|
| 曲杆能量法用 `dx` 而非 `ds=R dθ`，少乘一个 R | `energy_method.curved_ds` |
| 分段 EI 用一个值积到底，挠度差一个数量级 | `beam_deflection.ei_segments` |
| 开口环管无端盖 ⇒ `σ_l=0`，不是 `pD/4t` | `thin_wall_vessel.closed_or_open` |

## 8.3 结果

```
版本 0.3.0 | 31 张卡 | 99 条题型轴 + 5 条通用轴 | 76.4 KB
selftest  PASS 55 / FAIL 0    （31 张卡正确声明全 pass，不误报）
preflight PASS 10  WARN 27  FAIL 0
泄漏扫描  无 3 位以上小数、无已知答案数值
```

体积 76.4 KB，远低于 200 MB 知识库上限；**工具描述仍是 244 字符，加卡不增加每轮 token**
——这是卡库能扩到 31 张的前提。

## 8.4 仍未覆盖

30 张判据卡里「通用」类的 3 张（量纲检查 / 极限退化 / 单位统一）没有做成卡：它们是**校核动作**
不是建模决策，已在 `README` 硬规则 B 组与 `_common` 轴里体现。

另缺一整类：**流体、热、电磁**。周培源只考理论力学与材料力学，暂不扩。
