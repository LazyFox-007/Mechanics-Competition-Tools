# 现场录入协议（纸质赛题 → 文本通道）

> 前提变了：**赛题是纸质发放、不允许拍照**。
> 所以 `img_crop` / `mech-kit zoom` 那条「凡图必放大」无法执行——**没有图像文件可放大**。
> 本文件把「读图」这件事改成可操作的流程：**用户描述 → 我复述/画图 → 用户核对**。
> 对应 [AGENTS.md](../AGENTS.md) ⑤-1。

---

## 一、两条通道

| 方案 | 做法 | 何时用 | 成本 |
|---|---|---|---|
| **C（默认）** | 用户按模板描述 → **我用文字复述图形** → 用户逐条核对 | 绝大多数题 | ≈0，抓大部分读图错 |
| **B（加码）** | 同上，但我用 `scripts/draw_figure.py` **画出示意图** → 用户肉眼比对纸面图 | 几何复杂：多体、曲杆、锥面、机构、分步脱离 | 每题 +2~3 分钟 |

**为什么 C 就够用**：画图的价值不在"让我看见图"，而在**把理解暴露出来供人核对**。
我复述时一旦说错（"B 是固支"），用户立刻能发现；这与画不画图无关。

---

## 二、录入模板（照填，约 2 分钟）

```
【题号】第 X 题，共 XX 分
【题型】静力 / 运动 / 动力 / 材力 / 稳定
【已知】杆 AB 长 l、质量 m；斜面倾角 30°；块 C 重 P、高 h
【支座】A 固支｜B 铰支｜D 滚动（水平面）｜E 弹簧(k)
【载荷】中点 C 受竖直向下集中力 P；AB 段均布 q；A 端受力偶 M（逆时针）
【坐标系】x 向右，y 向上；θ 逆时针为正
【待求】(1) 反力 (2) 最大弯矩位置 (3) ...
【图形状】A 在左端固定；AB 水平；B 在右端铰支于墙；C 悬在 B 右侧
          P 的箭头竖直向下、画在中点；q 布满 AB 全段
```

**八行里最关键的是「图形状」**——不用画，用"谁在哪、朝哪、谁挨着谁"说清楚即可。

## 二·补　键盘码表（打不出希腊字母时）

**规则：希腊字母用完整英文单词，不用单字母缩写**（`a` 会和长度撞、`b` 和点 `B` 撞、`e` 和 `E` 撞）。

| 打 | 读 | 打 | 读 |
|---|---|---|---|
| `alpha` | α | `mu` | μ |
| `beta` | β | `rho` | ρ |
| `gamma` | γ | `sig` / `sigma` | σ |
| `delta` | δ | `tau` | τ |
| `Delta` | Δ（增量） | `phi` | φ |
| `eps` / `epsilon` | ε | `psi` | ψ |
| `theta` | θ | `omega` | ω |
| `lam` / `lambda` | λ | `Omega` | Ω |
| `pi` | π | `nu` | ν |

上下标与运算：`q1` `E2` `sig_max` ｜ `R^2` `10^3` ｜ `sqrt(3)` ｜ `1/2` ｜ `45deg` ｜ `<=` `>=` ｜ `->` ｜ `(vx,vy)`

单位照写：`mm` `kN` `MPa` `GPa` `rad/s` `mm2` `mm3`；科学计数 `12.8e3`。

**完整表见 [kb/theory/符号与键盘码表.md](../kb/theory/符号与键盘码表.md)**——那份进知识库，赛时会被检索注入。

## 三、必须问清的四件事（历届失分都在这）

| # | 必问 | 为什么 |
|---|---|---|
| 1 | **每个支座是什么类型** | 铰支常画成端部一个**空心小圆圈**，容易被当成"没画"。固支 / 铰支判错，约束方程个数就错 |
| 2 | **锥面 / 斜面的朝向** | "半径向外增大"还是"向内"，决定整条符号链。第十四届就栽在这 |
| 3 | **分步题：本问继承什么** | "P 是否仍作用""间隙是否已闭合""前问的约束是否已消失"。第十五届第 6 题栽在这 |
| 4 | **坐标系与正方向** | x/y 朝向、转角正负。与题目给的图不一致时，符号全反 |

> 这四问没答完，**不许动笔建模**。

## 四、B 方案：怎么让我画图核对

我用 `scripts/draw_figure.py` 按你的描述出图。你只需做一件事：**盯着屏幕图，逐项对纸面图**。

### 可用图元

| 类型 | 用途 | 关键字段 |
|---|---|---|
| `ground` | 地面 / 基线 | `x1,x2,y` |
| `beam` | 杆 / 梁 | `p1,p2,width` |
| `curved` | 圆弧杆 | `center,r,a1,a2` |
| `support` | 支座 | `kind`: fixed / pin / roller / spring |
| `node` | 节点 + 字母 | `at,label` |
| `force` | 集中力 | `at,dir,len,label` |
| `dist` | 分布载荷 | `p1,p2,dir,len,kind`: uniform / triangle |
| `moment` | 力偶 | `at,r,label,cw` |
| `dim` | 尺寸线 | `p1,p2,offset,label` |
| `block` | 物块 | `at,w,h,angle,label` |
| `circle` | 轮 / 滑轮 | `at,r,label,dashed` |
| `incline` | 斜面 | `p1,p2` |
| `rope` | 绳 | `p1,p2,dashed` |
| `angle` | 角度标注 | `at,r,a1,a2,label` |
| `text` | 注记 | `at,s,size` |

### 调用方式

```powershell
python scripts\draw_figure.py --spec fig.json --out fig.png
```

### 核对清单（用户逐条答"对/不对"）

1. 支座：**每个**位置的类型对不对？
2. 几何：长度关系、角度、谁和谁共线/垂直，对不对？
3. 载荷：方向、作用点、分布范围，对不对？
4. 连接：哪些是铰接、哪些是刚接、哪些是接触（光滑/有摩擦）？
5. 自由度：有没有我漏掉的构件或约束？

**任一条答"不对"，就改 spec 重画，不要靠猜往下算。**

## 五、输出必须是「抄写友好」格式

答案要用户**手抄到答题纸**，所以：

| 不要 | 要 |
|---|---|
| 长篇思路解释 | 骨架 + 关键式，解释压到一两句 |
| 嵌套分式 $\dfrac{a}{\frac{b}{c}}$ | 拆成两行，避免抄错层 |
| 一段话写三个结论 | 一行一个式子 |
| 复述题目 | 直接从模型开始 |
| 花式 LaTeX | 简单符号，手写省事 |

每题给完，附一行 **「抄写量估计」**（约几行 / 值不值得写），方便用户取舍。

## 六、时间账（这是最硬的约束）

```
120 分钟 ÷ 6 题 = 20 分钟/题
录入 3~5 分钟 + 抄写 6~10 分钟
⇒ 真正用于「算」的只有 5~10 分钟/题
```

**推论：**

- **优先提高题**（30 分/题），基础题分值低但录入+抄写成本一样
- **模型简单的题直接给结果式**，不要长篇推导
- **分工建议**：用户写解答更快时，就"用户写、我核"；我的价值在建模检查、算结果、给校核路径
- 每题开头一句话说明"这题值多少分钟"，超时就先拿分、不恋战

## 七、赛前演练（建议今晚做一次）

拿一道**有图的往届题**，只练这一段，不求完整解：

1. 用户按模板录入（**限时 4 分钟**）
2. 我复述图形（C）或画图（B）
3. 用户核对并指出错误
4. 评估：这一轮花了多少分钟？抄写量多大？

**练一次，明天就不慌。** 重点不是算对，是**测通道的耗时**。
