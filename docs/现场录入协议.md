# 现场录入协议（纸质赛题 → 文本通道）

> 前提：**赛题纸质发放、不允许拍照** ⇒ **没有图像文件**，`img_crop` / `zoom` 全部失效。
> 本文件规定「读图」这件事在现场怎么做，对应 [AGENTS.md](../AGENTS.md) ⑤-1。
>
> 一句话：**用户描述 → 我复述并出图 → 用户逐项核对 → 我改到对 → 才动笔。**

---

## 一、闭环五步（顺序不可跳）

| 步 | 谁做 | 动作 | 不可跳过 |
|---|---|---|---|
| 1 | 用户 | 按模板描述题目（见 §二） | — |
| 2 | 我 | **文字复述 + 出图**（`scripts/draw_figure.py`） | ✅ 不许只给文字 |
| 3 | 用户 | 拿屏幕图**逐项对照纸面图**，说"对/不对" | ✅ 不许默许 |
| 4 | 我 | **按纠正重画**，再给一次 | ✅ 不许口头接受就往下算 |
| 5 | 我 | 用户确认后才进建模 | ✅ **未确认就动笔 = 违规** |

**第 4 步是最容易偷懒的一步**：用户说"半圆柱朝向反了"，我不能只回一句"明白了，那应该……"然后开始算——
必须**重画一张**给他再看。因为"我理解对了"和"图画对了"是两件事，图是唯一能被人核对的产物。

## 二、录入模板（照填，约 2 分钟）

```
【题号】第 X 题，共 XX 分
【题型】静力 / 运动 / 动力 / 材力 / 稳定
【已知】杆 AB 长 l、质量 m；斜面倾角 30deg；块 C 重 P、高 h
【支座】A 固支｜B 铰支｜D 滚动（水平面）｜E 弹簧(k)
【载荷】中点 C 受竖直向下集中力 P；AB 段均布 q；A 端受力偶 M（逆时针）
【坐标系】x 向右，y 向上；theta 逆时针为正
【待求】(1) 反力 (2) 最大弯矩位置 (3) ...
【图形状】A 在左端固定；AB 水平；B 在右端铰支于墙；C 悬在 B 右侧
          P 的箭头竖直向下、画在中点；q 布满 AB 全段
【缺】theta 的起始边是水平还是竖直？B 的导轨是否水平？
```

**九行里最关键的是「图形状」和「缺」**：

- 「图形状」不用画，用"谁在哪、朝哪、谁挨着谁"说清
- **「缺」是主动交底**——凡是你自己读不准的，写出来，我就不会替你编

**五行版** —— 熟练后、时间紧时用：

```
T1 15分 动力
已知：边L；三角柱m、形心O1、J=?；半圆柱EF=L不计质量；杆AD长13L/5、m；A铰接
图：三角在左A在上，杆A→右下D触地，半圆柱夹在杆与地面间、EF贴杆、H触地
缺：J=？ M转向？
求：(1)D支撑力为零求M (2)...
```

**只有两行绝对不能省：【图形状】/ 图、以及【缺】。** 前者是所有"画错"的源头，后者是主动交底。

符号怎么打见 [符号表.md](../符号表.md)（希腊字母用英文单词：`theta` `omega` `sig`）。

## 三、核对清单（用户逐项答"对/不对"）

**几何**

1. 朝向：每个构件**摆向**对不对？（三角的顶点朝上还是朝下）
2. 相对位置：谁在左、谁在右、谁在上、谁在下
3. 共线与垂直：哪几条线是共线的？哪两条是垂直的？
4. 接触关系：**谁碰谁的哪一部分**（平边？弧？顶点？）
5. 触地/悬空：**哪些点接触地面，哪些点悬空**——这一条错得最多，见 §四

**约束与载荷**

6. 支座：每个位置的类型（固支/铰支/滚动/弹簧/自由）；铰支常画成**端部空心小圆圈**
7. 接触性质：光滑还是有摩擦；碰撞是弹性还是塑性；会不会分离
8. 载荷：方向、作用点、分布范围；力偶的**转向**
9. 数值：所有给定尺寸与参数**逐个念一遍**

**分步题**

10. 第 (2)(3) 问：本问继承什么？什么已消失？

> 任一条答"不对"→ 回到第 4 步重画。

## 四、两类"默认值陷阱"（我最容易猜错的地方）

我画图时会不自觉地套用**最常见的画法**，而力学题恰恰常把它反过来。必须显式问：

| 陷阱 | 常见默认 | 实际可能相反 |
|---|---|---|
| **半圆柱 / 半圆盘朝向** | 平边贴地、弧朝上 | **平边贴杆、弧朝下触地**（当滚子用） |
| **锥体 / 圆台朝向** | 上粗下细（受拉） | **上细下粗**（悬挂自重，顶部受力最大反而更细） |
| **三角 / 多边形摆向** | 一个顶点朝上 | **顶点朝下压在地面** |
| **力偶转向** | 逆时针 | 顺时针 |

**规则：这四类必须逐条问，不许按默认画。**

## 五、尺寸自洽性检查（最强的验证手段）

**如果几个给定尺寸能凑成整数比 / 勾股数 / 特殊角，说明理解对了；凑不出来，八成是理解错了。**

实例（15 届第 1 题）：

```
A 离地 L（莱洛三角顶点）
D 触地                ⇒ 垂直落差 = L
AD = 13L/5            ⇒ 水平跨 = sqrt((13/5)²−1)·L = 12L/5

5-12-13 直角三角形：sin = 5/13，cos = 12/13   ← 干净到不可能是巧合
```

由此反推出所有点坐标都是精确值：

```
O2 = AD 中点 (1.2L, 0.5L)          ← 只有 |O2H| = L/2 时才成立
E  = A + 0.8·L·(12/13, −5/13)
F  = A + 1.8·L·(12/13, −5/13)
H  = (1.2L, 0)                     ← O2 正下方
```

**做法**：出图后我主动算一次几何自洽性，把结果一并告诉用户；若算不出整数关系，先怀疑自己的理解，而不是怀疑题目。

## 六、案例：15 届第 1 题（v1 → v2）

**v1（我按 OCR 文字自己理解的，错的）**

```
半圆柱 EHF：平边 EF 贴地、弧朝上（最常见的画法）
E、F 触地；杆 AD 架在半圆柱顶部
```

**用户的一句话纠正**

> 「EF 点和 AD 杆共线且不接触地面，接触地面的是 H 点，然后 D 点接触地面」

**v2（修正后）**

```
半圆柱是夹在【杆】和【地面】之间的滚子：
  平边 EF 与杆 AD 共线（贴在杆的下侧），E、F 悬空
  弧在 H 点触地并纯滚动
  杆 AD 从 A 穿过 E、O2、F，最后 D 端触地
```

**这次纠正的价值**：不是"我漏了一个细节"，而是**整个机构的受力路径都变了**——
v1 里半圆柱是"垫在下面的支座"，v2 里它是"传力的滚子"。图错，模型必错。

**教训（已并入 §四）**：半圆柱/半圆盘的朝向必须问，不能按默认。

## 七、输出必须是「抄写友好」格式

答案要用户**手抄到答题纸**，所以：

| 不要 | 要 |
|---|---|
| 长篇思路解释 | 骨架 + 关键式，解释压到一两句 |
| 嵌套分式 $\dfrac{a}{\frac{b}{c}}$ | 拆成两行 |
| 一段话写三个结论 | 一行一个式子 |
| 复述题目 | 直接从模型开始 |
| 花式 LaTeX | 简单符号，手写省事 |

每题给完，附一行**「抄写量估计」**（约几行 / 值不值得写）。

## 八、时间账

```
120 分钟 ÷ 6 题 = 20 分钟/题
录入 3~5 分钟 + 出图核对 2~3 分钟 + 抄写 6~10 分钟
⇒ 真正用于「算」的只有 3~8 分钟/题
```

**推论：**

- **优先提高题**（30 分/题）；基础题分值低但录入+抄写成本一样
- 模型简单的题直接给结果式，不写长篇推导
- **分工建议**：用户写解答更快时，就"用户写、我核"；我的价值在建模检查、算结果、给校核路径
- 每题开头一句话说明"这题值多少分钟"，超时就先拿分

## 九、画图工具速查

```powershell
python scripts\draw_figure.py --spec fig.json --out fig.png
```

**16 种图元**（见 `scripts/draw_figure.py` 文件头）：
`ground` `beam` `curved` `support` `node` `force` `dist` `moment` `dim`
`block` `circle` `incline` `rope` `angle` `hatch` `text` `taper`

**可用示例**：[`figure_specs/15届第1题.json`](figure_specs/15届第1题.json) —— 上面 v2 的完整 spec，改坐标就能复用。

**自动自检**（每次出图都会打印）：

| 检查 | 报什么 |
|---|---|
| 标签重叠 | `标签重叠 62% 「E2=5E」×「截面」` |
| 超出画布 | `超出画布 「F」` |
| 缺字形 | `Glyph 8658 (⇒) missing from font` → 会渲染成方块 |

**看到警告就改 spec 重画，不要带着警告交付。**
