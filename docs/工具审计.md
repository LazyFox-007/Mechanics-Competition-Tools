# 工具审计（2026-10-28）

依据：用本仓库现有工具 + 全局 MCP，实做 3 道周培源真题（十四届-3、十五届-2、十二届-2），
记录**每一处被迫绕路**的地方，再回头审这套工具够不够、顺不顺。

结论先说：**求解能力够，边界能力缺**。
19 项校核全过、答案可复现，说明 `sympy` / `sympy-physics` / 插件那条线是可靠的；
9 次重试里有 6 次与力学无关，全部落在「跑脚本、裁图、看图、打包」四件事上。

## 一、现有工具：哪些好、哪些碍事

| 项 | 比赛中的角色 | 审计结论 | 处置 |
|---|---|---|---|
| `mcp/sympy`（32 工具） | 符号推导主力 | **可用但太重**：32 个 schema 常驻上下文；且与全局已装的 `sympy` 重复 | 二选一。只留本仓库这份，或只留全局那份，**不要两份都开** |
| `mcp/sympy-physics`（7 工具） | 拉格朗日 / 梁 / 单位 | **高价值**：`lagrange_eom`、`beam_solve`、`unit_check` 正好补 `sympy` 的缺口 | 保留，赛时必开 |
| `mcp/lean4`（3 工具） | 形式化证明 | **基本用不上**：力学竞赛没有形式化证明题型；3 个 schema 纯占上下文 | 建议默认 `disabled: true`，需要时再开 |
| `plugins/dsh-mech-workbench`（9 工具） | 读题图、反力与 N/Q/M/T、莫尔圆、出图自检 | **高价值但有个前提**：必须用创造模式装、装完重启。**没装 = 等于没有** | 赛前 30 分钟装好并实际调一次（别到赛时才发现没生效） |
| `skills/mechanics-map`（17 章） | 教材查阅 | 内容好，但**没有索引**：靠模型逐文件读，token 不可控 | 建议加 `index.json`（章/节 → 文件 + 行号），先查索引再读片段 |
| `skills/mechanics-zh` | 中文速查、符号约定 | 好，短小 | 保留，赛前当“约定卡”读一遍 |
| `skills/undergrad-physics-skill` | 八步验算流程 | **流程本身是得分点**（过程分 20%） | 保留；其中 F/B/L 可逐步由 `scan_extremum` / `numeric_compare` 落地 |

### 一个真问题：插件没装

`mech_analyze` / `mech_diagram` / `mech_read_problem` 是本仓库最值钱的三个工具，
但它们**不在 MCP 里**，`setup.ps1` 装不了，必须走创造模式。这次演练就没装成，
读题只能退回 `pdf_text` + 人眼，等于把最贵的一环交给了运气。

> 建议：在 `setup.ps1` 的收尾清单里把「装插件」从第 1 条提示升级成**带检查的步骤**——
> 跑完问一句 `cordis_inspect_query`，确认 `dsh-mech-workbench` 行存在，否则红字警告。

## 二、缺的四类能力 → 已补成 `mcp/mech-io`

| 缺什么 | 比赛中的实际损失 | 补的工具 |
|---|---|---|
| 安全地跑 Python | 中文路径/引号被 shell 拆坏；GBK 让 `print` 崩，脚本跑完拿不到结果 | `py_run` |
| 图像/PDF 局部取图 | 预览图与原图像素比例不同，按像素裁必错；整页渲染再裁又糊 | `img_crop`、`pdf_page_crop` |
| 图形自检 | 阴影区画反、两层压成一条线、下标缺字形，全靠人眼一张张看 | `fig_lint`、`plot_audit` |
| 交付打包 | 手建目录、手抄命名、手算哈希、手搓 HTML→PDF | `submission_pack`、`html_to_pdf` |
| 独立校核样板 | 每题重写 meshgrid / 残差脚本，口径不统一 | `scan_extremum`、`numeric_compare` |

自测 **16/16 通过**（`mcp/mech-io/test/selftest.py`）。

## 三、还缺（这次没做，列入待办）

| 缺口 | 现状 | 建议 |
|---|---|---|
| **公式 OCR** | 只能裁图后由模型看。这次 `E₁=E₃=E₂/5=E` 就是靠放大才确认 | 本地 [pix2text](https://atomgit.com/gh_mirrors/pi/Pix2Text) 或 MinerU，包成 `formula_ocr(page, box) → LaTeX`；注意模型体积与 200 MB 知识库上限 |
| **Token 计量** | 只能报字数/图数；赛规同分看 token | DSH 已有 `token-meter`，缺一个 `session_usage()` 出口把每轮 in/out 落盘 |
| **错题沉淀** | 易错点只写在过程日志里，下次不会自动生效 | 把「落点要加初始横坐标」「上缘曲率半径≠中性层半径」这类做成可检索卡片，赛前注入 |
| **知识库索引** | `mechanics-map` 17 章靠模型自己翻 | `index.json` + 一个 `kb_search` 工具（纯本地，不联网） |
| **计时** | 3.5 小时赛时，没有分段提醒 | 轻量 `timer`（可选，价值中等） |
